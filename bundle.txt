# PROJECT HANDOFF — Cleanup YOLO/LaMa

Stand: 15. November 2026
Projektpfad: ~/Downloads/Cleanup
Sprache der Zusammenarbeit: Deutsch

## 1. Projektziel

Das Projekt entfernt unerwünschte Schrift und andere ausgewählte Elemente aus
Bildern. Sprite-Details, Farben, Konturen und natürliche Bildstrukturen sollen
möglichst erhalten bleiben.

Die Hauptpipeline erzeugt mehrere Maskenkandidaten, verarbeitet diese mit
YOLO/LaMa, bewertet die Ergebnisse und speichert pro Bild eine ausgewählte
Variante samt Masken, Kandidatenbildern und Berichten.

## 2. Hauptpipeline und Module

`yolo_mask_auto_select.py`
  Schlanker Programmeinstieg. Importiert `main()` aus dem Pipeline-Modul.

`yolo_mask_auto_select_modules/config.py`
  Zentrale Pfade, Modell- und Laufparameter, aktive Kandidatenvarianten,
  Schwellenwerte und Bewertungsgewichte. Die gemeinsamen Standardpfade sind:
  - CSV-Verzeichnis: `~/Downloads/yabai proj/output/csv/`
  - Anchors: `anchors.csv` in diesem Verzeichnis
  - optionale Schutzzonen: `protected_zones.csv` im selben Verzeichnis
  - Quellbilder: `~/Downloads/yabai proj/mit_kanji/`
  - optionale Schutzzonen: `protected_zones.csv` neben der aktiven Anchors-CSV.
  Pipeline, Routing-Audit und Label-Tool verwenden dieselben Defaults.
  Abweichende Speicherorte können per CLI angegeben werden. Für aktuelle
  Einstellungen ist ausschließlich diese Datei maßgeblich; alte Logs und
  Backups können abweichende historische Werte enthalten.

`yolo_mask_auto_select_modules/cli.py`
  Kommandozeilenargumente für Bilder, Anchors, YOLO-Gewichte, Stichprobe,
  Distanzen, Geräte, Ausgabe und Dry-Run.

`yolo_mask_auto_select_modules/io_utils.py`
  Bild- und CSV-Verarbeitung, Quellenfindung, Anchor-/Box-Masken,
  Alpha-Nachbearbeitung und zugehörige I/O-Helfer.

`yolo_mask_auto_select_modules/scoring.py`
  Metriken zur Kandidatenbewertung und Auswahl. Dazu gehören unter anderem
  Textreste, Detailerhaltung, Konturen, Strukturveränderungen, Leaks,
  Box-only-Rescue und Residual-Micro-Components.

`yolo_mask_auto_select_modules/pipeline.py`
  Orchestriert YOLO-Kandidaten, Maskenvarianten, LaMa-Verarbeitung,
  Bewertung, Auswahl und Speicherung.

`yolo_mask_auto_select_modules/debug_output.py`
  Debug-Overlays, Kontaktbögen und Vorher-/Nachher-Vergleiche.

`yolo_mask_auto_select_modules/reports.py`
  CSV-Ausgabe mit der Vereinigung der bevorzugten und tatsächlich vorhandenen
  Metrikfelder. Verhindert Abbrüche, wenn neue Score-Felder hinzukommen.

===== README.md =====

# Cleanup — YOLO/LaMa image cleanup

This repository contains a YOLO/LaMa pipeline for removing unwanted text or
other selected elements from images while trying to preserve sprite details,
colors, outlines, and surrounding image structure.

The main workflow generates mask candidates, evaluates them, selects a winner,
and stores masks, cleaned candidates, and reports under `yolo_mask_winners/`.

## Main pipeline

`yolo_mask_auto_select.py` is the command-line entry point. Keep it beside
`yolo_mask_auto_select_modules/` and `yolo_mask_routing_audit.py`.

The module package separates the implementation:

- `config.py`: shared paths, model settings, thresholds, and scoring configuration.
  The default `anchors.csv` is read from
  `~/Downloads/yabai proj/output/csv/anchors.csv`; optional
  `protected_zones.csv` is discovered beside the selected anchors file.
- `cli.py`: command-line arguments.
- `io_utils.py`: image/CSV discovery, anchor handling, masks, and I/O helpers.
- `scoring.py`: candidate metrics and candidate selection.
- `pipeline.py`: YOLO/LaMa orchestration, evaluation, selection, and output.
- `debug_output.py`: overlays, contact sheets, and comparison images.
- `reports.py`: CSV output with dynamically collected metric columns.

Candidate variants include YOLO distance-clipped masks and a Box-only fallback.
The currently active variant set and thresholds are defined in
`yolo_mask_auto_select_modules/config.py`; do not infer current values from
old run logs or archived configuration backups.

## Supporting tools

These are separate utilities, not duplicate pipeline implementations:

- `yolo_mask_routing_audit.py`: reruns YOLO inference to inspect instance
  masks, distance clipping, and body-box coverage. It writes routing reports,
  per-box metrics, instance details, and visual contact sheets. It does not
  run LaMa or modify source images.
- `label_tool.py`: local browser-based UI for manually rating generated
  candidates. It writes `labels.csv` in the selected run directory.
- `train_ranker.py`: trains and evaluates a candidate ranker from the
  candidate score CSV and manual labels.
- `build_final_picks.py`: combines ranker predictions with manual labels and
  can copy the final accepted candidate images into a separate folder.
- `scripts/cleanup_repo.py`: reports repository cleanup candidates by
  default; with `--apply`, removes Python caches and archives old backups,
  the known accidental patch dump, and root-level log files outside the repo.

## CSV and source paths

The pipeline, standalone routing audit, and labeling tool share the defaults
from `yolo_mask_auto_select_modules/config.py`:

- CSV directory: `~/Downloads/yabai proj/output/csv/`
- Anchors: `anchors.csv` in that directory.
- Optional protected zones: `protected_zones.csv` in that directory.
- Source images: `~/Downloads/yabai proj/mit_kanji/`

All three tools support their existing command-line path overrides. If the
anchors CSV is moved, pass its new path with `--anchors`; protected zones
will then be discovered beside that file unless an explicit protected CSV
path is supplied. Run-specific CSVs such as `labels.csv` and
`candidate_scores.csv` remain inside their respective run directories.

## Run the pipeline

From the repository root:

```bash
source .venv/bin/activate
python -m py_compile yolo_mask_auto_select.py yolo_mask_routing_audit.py yolo_mask_auto_select_modules/*.py
python yolo_mask_auto_select.py --random-sample 10 --min-m-images 3 --seed 20261018 --dry-run
```

Remove `--dry-run` only when you intend to start processing. Check the

## Tests

Run the repository's unit tests with:


The tests cover dynamic candidate-score CSV columns, Box-only rescue behavior,

## Result and diagnostic data

- `yolo_mask_winners/` contains generated winner masks, candidate images,

- `diagnostics/` contains selected diagnostic evidence and replay reports.
  These files are intentionally kept.
- The older `requirements-before-iopaint.txt` is a historical environment

Never delete result images or diagnostic reports solely because they are
generated. Remove them only after confirming that they are no longer needed.

#!/usr/bin/env python3
"""Combine your hand labels with the ranker into one final pick per image.

Priority per image:
  1. You labeled it with at least one acceptable candidate
       -> use the ranker's pick if you accepted it, else its runner-up if accepted,
          else the first accepted candidate in a fixed preference order. (source=label)
  2. You marked it "none good"            -> status needs_mask_fix, no winner copied
  3. You skipped it                       -> status needs_review
  4. Not labeled                          -> ranker pick (source=ranker);
                                             low-confidence ones get status needs_review

    python build_final_picks.py --run-dir <RUN> [--copy]

--copy gathers winning images into <RUN>/final_winners/ (copies, never moves/deletes
anything) and writes <RUN>/final_picks.csv.
"""
from __future__ import annotations

import argparse
import shutil
from pathlib import Path

import pandas as pd

PREFER = ["HYBRID_D6", "HYBRID_D2", "BOX_ONLY", "2", "4", "6", "8", "10", "0",
          "CONTRAST_T38", "SMART_INK"]
FILE_SUFFIX = {"BOX_ONLY": "box_only", "CONTRAST_T38": "contrast_t38", "HYBRID_D2": "hybrid_d2",
               "HYBRID_D6": "hybrid_d6", "SMART_INK": "smart_ink"}


def cand_file(image_stem: str, cand: str) -> str:
    suf = FILE_SUFFIX.get(cand) or f"distance_{int(cand):02d}px"
    return f"{image_stem}__{suf}.png"


def stem(s: str) -> str:
    return Path(str(s)).stem


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--run-dir", type=Path, required=True)
    ap.add_argument("--ranker-picks", type=Path)
    ap.add_argument("--labels", type=Path)
    ap.add_argument("--copy", action="store_true", help="copy winning images to final_winners/")
    a = ap.parse_args()
    run = a.run_dir
    picks = pd.read_csv(a.ranker_picks or run / "ranker_out" / "ranker_picks.csv", encoding="utf-8-sig")
    labels = pd.read_csv(a.labels or run / "labels.csv", encoding="utf-8-sig")
    picks["img"] = picks["image"].map(stem)
    labels["img"] = labels["image"].map(stem)
    labels["candidate"] = labels["candidate"].astype(str)

    lab = {}
    for img, d in labels.groupby("img"):
        lab[img] = {"good": set(d.loc[d.good == 1, "candidate"]),
                    "none": int(d.none_good.max()) == 1, "skip": int(d.skipped.max()) == 1}

    rows = []
    for r in picks.itertuples():
        img = r.img
        pick, runner = str(r.ranker_pick), str(r.runner_up)
        row = {"image": img + ".png", "winner": "", "source": "", "status": "", "ranker_pick": pick,
               "top_prob": r.top_prob}
        L = lab.get(img)
        if L is None:
            row.update(winner=pick, source="ranker",
                       status="needs_review" if r.needs_review else "auto_accepted")
        elif L["none"]:
            row.update(source="label", status="needs_mask_fix")
        elif L["skip"] and not L["good"]:
            row.update(source="label", status="needs_review")
        else:
            good = L["good"]
            if pick in good:
                w = pick
            elif runner in good:
                w = runner
            else:
                w = next((c for c in PREFER if c in good), sorted(good)[0] if good else "")
            row.update(winner=w, source="label", status="labeled_ok" if w else "needs_review")
        rows.append(row)
    out = pd.DataFrame(rows)
    out.to_csv(run / "final_picks.csv", index=False, encoding="utf-8-sig")

    print(out.status.value_counts().to_string())
    print(f"\nWrote {run/'final_picks.csv'}")

    if a.copy:
        src = run / "debug_candidates" / "cleaned_images"
        dst = run / "final_winners"
        dst.mkdir(exist_ok=True)
        n = miss = 0
        for r in out[out.winner != ""].itertuples():
            f = src / cand_file(Path(r.image).stem, str(r.winner))
            if f.is_file():
                shutil.copy2(f, dst / (Path(r.image).stem + ".png")); n += 1
            else:
                miss += 1
        print(f"Copied {n} winners to {dst} ({miss} source files missing)")
        for status in ("needs_mask_fix", "needs_review"):
            lst = out[out.status == status].image.tolist()
            (run / f"list_{status}.txt").write_text("\n".join(lst), encoding="utf-8")
        print("Wrote list_needs_mask_fix.txt and list_needs_review.txt")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""Local labeling tool: mark which cleaned candidates are acceptable.

Standalone (stdlib + numpy + Pillow). Does not touch the pipeline.

    python label_tool.py \
        --run-dir /home/secret/Downloads/Cleanup/yolo_mask_winners/full_recheck_after_alpha_island_025_20261025_022053

Then open http://127.0.0.1:8765 . Labels are saved to <run-dir>/labels.csv after
every image (one row per candidate), so you can stop and resume at any time.
"""
from __future__ import annotations

import argparse
import csv
import hashlib
import json
import random
import re
import threading
import time
import webbrowser
from collections import defaultdict
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from io import BytesIO
from pathlib import Path
from urllib.parse import parse_qs, unquote, urlparse

import numpy as np
from PIL import Image

from yolo_mask_auto_select_modules.config import DEFAULT_ANCHORS_CSV, DEFAULT_IMAGES_DIR

DEFAULT_IMAGES = DEFAULT_IMAGES_DIR
DEFAULT_ANCHORS = DEFAULT_ANCHORS_CSV
IMAGE_EXTS = {".png", ".jpg", ".jpeg", ".webp", ".bmp", ".tif", ".tiff"}

# file suffix -> candidate id used in candidate_scores.csv ("distance_px" column)
SPECIAL = {"box_only": "BOX_ONLY", "contrast_t38": "CONTRAST_T38",
           "hybrid_d2": "HYBRID_D2", "hybrid_d6": "HYBRID_D6", "smart_ink": "SMART_INK"}
CAND_ORDER = ["0", "2", "4", "6", "8", "10", "HYBRID_D2", "HYBRID_D6",
              "CONTRAST_T38", "SMART_INK", "BOX_ONLY"]


def suffix_to_id(suffix: str) -> str | None:
    if suffix in SPECIAL:
        return SPECIAL[suffix]
    m = re.fullmatch(r"distance_(\d+)px", suffix)
    return str(int(m.group(1))) if m else None


class Store:
    def __init__(self, a):
        self.run = a.run_dir.resolve()
        self.cleaned = self.run / "debug_candidates" / "cleaned_images"
        if not self.cleaned.is_dir():
            raise SystemExit(f"Not found: {self.cleaned}")
        self.labels_path = a.labels or (self.run / "labels.csv")
        self.margin = a.margin
        self.snap = a.snap
        self.lock = threading.Lock()

        # candidate files per image
        self.cands: dict[str, dict[str, Path]] = defaultdict(dict)
        for p in sorted(self.cleaned.glob("*.png")):
            stem, sep, suf = p.stem.partition("__")
            cid = suffix_to_id(suf) if sep else None
            if cid:
                self.cands[stem][cid] = p
        if not self.cands:
            raise SystemExit("No candidate images recognised.")

        # originals
        print("Indexing source images ...")
        self.orig: dict[str, Path] = {}
        want = {f"{s}" for s in self.cands}
        for p in a.images_dir.expanduser().rglob("*"):
            if p.suffix.lower() in IMAGE_EXTS and p.stem in want:
                self.orig.setdefault(p.stem, p)
        print(f"  originals found: {len(self.orig)}/{len(self.cands)}")

        # anchors
        self.boxes: dict[str, list[dict]] = defaultdict(list)
        if a.anchors.is_file():
            with a.anchors.open(encoding="utf-8-sig", newline="") as f:
                for r in csv.DictReader(f):
                    try:
                        name = Path((r.get("image") or "").strip()).stem
                        self.boxes[name].append({
                            "type": (r.get("type") or "").strip().lower(),
                            **{k: float(r[k]) for k in ("x1", "y1", "x2", "y2")}})
                    except (ValueError, KeyError, TypeError):
                        continue
        else:
            print(f"WARN: anchors not found ({a.anchors}); showing full images")

        # current winners (hidden in UI by default to avoid biasing labels)
        self.winner: dict[str, str] = {}
        wr = self.run / "winner_report.csv"
        if wr.is_file():
            with wr.open(encoding="utf-8-sig", newline="") as f:
                for r in csv.DictReader(f):
                    self.winner[Path(r["image"]).stem] = str(r.get("selected_distance_px", "")).strip()

        self.order = self._make_order(a)
        self.labels: dict[str, dict] = {}
        self._load_labels()
        self.ranker: dict[str, str] = {}
        if a.queue:
            if not a.queue.is_file():
                raise SystemExit(f"--queue file not found: {a.queue}")
            rows = []
            with a.queue.open(encoding="utf-8-sig", newline="") as f:
                for r in csv.DictReader(f):
                    n = Path(r["image"]).stem
                    self.ranker[n] = str(r.get("ranker_pick", ""))
                    if str(r.get("needs_review", "0")) == "1" and n in self.cands:
                        rows.append((float(r.get("top_prob") or 1), n))
            self.order = [n for _, n in sorted(rows)]
            print(f"Queue: {len(self.order)} images flagged needs_review (least confident first)")
        if not a.include_labeled:
            self.order = [n for n in self.order if n not in self.labels]
        self.hash_cache: dict[str, dict] = {}

    # ---- ordering: hard images interleaved with random ones (avoids bias)
    def _make_order(self, a) -> list[str]:
        names = sorted(self.cands)
        if a.order == "name":
            return names
        rng = random.Random(a.seed)
        rnd = names[:]
        rng.shuffle(rnd)
        if a.order == "random":
            return rnd
        spread: dict[str, float] = {n: 0.0 for n in names}
        cs = self.run / "candidate_scores.csv"
        if not cs.is_file():
            cs = self.run / "debug_candidates" / "candidate_scores.csv"
        if not cs.is_file() and a.scores:
            cs = Path(a.scores)
        if not cs.is_file():
            print("WARN: candidate_scores.csv not found; 'hard first' ordering disabled")
        if cs.is_file():
            vals = defaultdict(lambda: defaultdict(list))
            with cs.open(encoding="utf-8-sig", newline="") as f:
                for r in csv.DictReader(f):
                    n = Path(r["image"]).stem
                    for k in ("text_quality_score", "score"):
                        try:
                            vals[n][k].append(float(r[k]))
                        except (KeyError, ValueError):
                            pass
            for n, d in vals.items():
                s = sum((max(v) - min(v)) for v in d.values() if v)
                tq = d.get("text_quality_score", [])
                if tq and max(tq) == 0:
                    s += 0.5  # all-zero ties: scorer cannot discriminate
                spread[n] = s
        hard = sorted(names, key=lambda n: -spread[n])
        if a.order == "hard":
            return hard
        out, seen = [], set()
        for h, r in zip(hard, rnd):
            for n in (h, r):
                if n not in seen:
                    seen.add(n); out.append(n)
        return out

    # ---- labels
    def _load_labels(self):
        if not self.labels_path.is_file():
            return
        with self.labels_path.open(encoding="utf-8-sig", newline="") as f:
            for r in csv.DictReader(f):
                d = self.labels.setdefault(r["image"], {"good": set(), "none": False, "skipped": False})
                if r["good"] == "1":
                    d["good"].add(r["candidate"])
                if r.get("none_good") == "1":
                    d["none"] = True
                if r.get("skipped") == "1":
                    d["skipped"] = True

    def _write_labels(self):
        tmp = self.labels_path.with_suffix(".tmp")
        with tmp.open("w", encoding="utf-8-sig", newline="") as f:
            w = csv.writer(f)
            w.writerow(["image", "candidate", "good", "none_good", "skipped", "labeled_at"])
            stamp = time.strftime("%Y-%m-%d %H:%M:%S")
            for img, d in self.labels.items():
                for cid in CAND_ORDER:
                    if cid in self.cands.get(img, {}):
                        w.writerow([img, cid, int(cid in d["good"]), int(d["none"]),
                                    int(d["skipped"]), stamp])
        tmp.replace(self.labels_path)

    def save_label(self, img, good, none, skipped):
        with self.lock:
            self.labels[img] = {"good": set(good), "none": bool(none), "skipped": bool(skipped)}
            self._write_labels()

    # ---- cropping / dedupe
    def crop_rect(self, name: str, m: str = "") -> tuple[int, int, int, int]:
        margin = self.margin
        if m == "full":
            margin = None
        elif m.isdigit():
            margin = int(m)
        any_path = next(iter(self.cands[name].values()))
        with Image.open(any_path) as im:
            w, h = im.size
        bs = self.boxes.get(name)
        if not bs or margin is None:
            return 0, 0, w, h
        x1 = min(b["x1"] for b in bs) - margin
        y1 = min(b["y1"] for b in bs) - margin
        x2 = max(b["x2"] for b in bs) + margin
        y2 = max(b["y2"] for b in bs) + margin
        x1, y1 = max(0, int(x1)), max(0, int(y1))
        x2, y2 = min(w, int(np.ceil(x2))), min(h, int(np.ceil(y2)))
        if x2 - x1 < 8 or y2 - y1 < 8:
            return 0, 0, w, h
        # Snap to image edges so near-edge content is never trimmed by a few px.
        snap = self.snap
        if x1 <= snap: x1 = 0
        if y1 <= snap: y1 = 0
        if w - x2 <= snap: x2 = w
        if h - y2 <= snap: y2 = h
        if (x2 - x1) * (y2 - y1) >= 0.85 * w * h:
            return 0, 0, w, h
        return x1, y1, x2, y2

    def info(self, name: str, m: str = "") -> dict:
        key = f"{name}|{m}"
        if key in self.hash_cache:
            return self.hash_cache[key]
        rect = self.crop_rect(name, m)
        groups: dict[str, list[str]] = {}
        for cid in CAND_ORDER:
            p = self.cands[name].get(cid)
            if not p:
                continue
            with Image.open(p) as im:
                arr = np.asarray(im.convert("RGBA").crop(rect))
            groups.setdefault(hashlib.md5(arr.tobytes()).hexdigest(), []).append(cid)
        info = {"rect": rect, "groups": list(groups.values())}
        self.hash_cache[key] = info
        return info

    def png(self, name: str, which: str, m: str = "") -> bytes:
        path = self.orig.get(name) if which == "orig" else self.cands[name].get(which)
        if path is None:
            raise FileNotFoundError(which)
        with Image.open(path) as im:
            im = im.convert("RGBA").crop(self.crop_rect(name, m))
        buf = BytesIO()
        im.save(buf, "PNG")
        return buf.getvalue()

def make_handler(store: Store):
    class H(BaseHTTPRequestHandler):
        def log_message(self, *a):
            pass

        def _send(self, code, body, ctype):
            self.send_response(code)
            self.send_header("Content-Type", ctype)
            self.send_header("Content-Length", str(len(body)))
            self.end_headers()
            self.wfile.write(body)

        def _json(self, obj):
            self._send(200, json.dumps(obj).encode(), "application/json")

        def do_GET(self):
            parsed = urlparse(self.path)
            path = unquote(parsed.path)
            m = (parse_qs(parsed.query).get("m") or [""])[0]
            try:
                if path == "/":
                    return self._send(200, HTML.encode(), "text/html; charset=utf-8")
                if path == "/api/queue":
                    return self._json([{"name": n, "labeled": n in store.labels} for n in store.order])
                if path.startswith("/api/image/"):
                    n = path[len("/api/image/"):]
                    inf = store.info(n, m)
                    d = store.labels.get(n, {"good": set(), "none": False})
                    return self._json({"name": n, "rect": inf["rect"], "groups": inf["groups"],
                                       "good": sorted(d["good"]), "none": d["none"],
                                       "winner": store.winner.get(n, ""), "ranker": store.ranker.get(n, "")})
                mm = re.fullmatch(r"/crop/([^/]+)/([^/]+)\.png", path)
                if mm:
                    return self._send(200, store.png(mm.group(1), mm.group(2), m), "image/png")
            except Exception as e:  # noqa: BLE001
                return self._send(500, str(e).encode(), "text/plain")
            self._send(404, b"not found", "text/plain")

        def do_POST(self):
            if urlparse(self.path).path == "/api/save":
                body = json.loads(self.rfile.read(int(self.headers["Content-Length"])))
                store.save_label(body["image"], body["good"], body["none"], body["skipped"])
                return self._json({"ok": True})
            self._send(404, b"not found", "text/plain")
    return H

#!/usr/bin/env python3
"""Conservative repository cleanup for the Cleanup YOLO/LaMa project.

Default: report only, make no changes.
Apply:   python scripts/cleanup_repo.py --apply

The script removes regenerable Python bytecode/cache files. Old source
backups, the known accidental patch dump, and root-level historical logs are
moved to a timestamped archive next to the repository before disappearing
from the working tree.

Diagnostics, tests, source code, requirements snapshots, and all
yolo_mask_winners data are deliberately preserved. A static import audit
may report possible orphan modules, but it never deletes code.
"""
from __future__ import annotations

import argparse
import ast
import datetime as dt
import os
import re
import shutil
from pathlib import Path


BACKUP_NAME_RE = re.compile(
    r"(?:\.bak(?:[._-].*)?|\.backup(?:[._-].*)?|\.old|\.orig)$",
    re.IGNORECASE,
)
SKIP_DIRS = {
    ".git",
    ".venv",
    "venv",
    "env",
    "node_modules",
    ".tox",
    ".mypy_cache",
    ".pytest_cache",
}
PROTECTED_ROOT_DIRS = {
    "yolo_mask_winners",  # selected masks, candidate images and reports
}


def default_repo_root() -> Path:
    return Path(__file__).resolve().parents[1]


def walk_repository(root: Path):
    """Yield paths without following symlinks or entering protected trees."""
    for current, dirnames, filenames in os.walk(root, topdown=True, followlinks=False):
        current_path = Path(current)
        kept_dirs: list[str] = []
        for dirname in sorted(dirnames):
            candidate = current_path / dirname
            if dirname in SKIP_DIRS or candidate.is_symlink():
                continue
            if current_path == root and dirname in PROTECTED_ROOT_DIRS:
                continue
            kept_dirs.append(dirname)
        dirnames[:] = kept_dirs
        yield current_path, list(sorted(filenames)), list(sorted(dirnames))


def is_known_patch_dump(path: Path) -> bool:
    """Recognise the one accidental Git diff file in the inspected repo."""
    expected_name = "tore -- " + chr(92)
    if path.name != expected_name or not path.is_file() or path.is_symlink():
        return False
    try:
        text = path.read_text(encoding="utf-8", errors="replace")[:4096]
    except OSError:
        return False
    # The committed file contains ANSI color escapes around a unified Git diff.
    return "diff --git a/" in text and "+++ b/" in text


def collect_cleanup_targets(root: Path) -> dict[str, list[Path]]:
    targets: dict[str, list[Path]] = {
        "cache_dirs": [],
        "bytecode_files": [],
        "backup_files": [],
        "patch_dumps": [],
        "log_files": [],
    }

    for current, filenames, dirnames in walk_repository(root):
        for dirname in dirnames:
            if dirname == "__pycache__":
                cache_dir = current / dirname
                if cache_dir.is_dir() and not cache_dir.is_symlink():
                    targets["cache_dirs"].append(cache_dir)

        for filename in filenames:
            path = current / filename
            if path.is_symlink() or not path.is_file():
                continue
            lower_name = filename.lower()

            if path.suffix.lower() in {".pyc", ".pyo"}:
                # Files inside a cache directory are removed with that directory.
                if "__pycache__" not in path.parts:
                    targets["bytecode_files"].append(path)
                continue

            if BACKUP_NAME_RE.search(lower_name):
                targets["backup_files"].append(path)
                continue

            # Only root-level logs are archived. Logs nested inside diagnostics
            # remain with their reports and evidence.
            if path.suffix.lower() == ".log" and path.parent == root:
                targets["log_files"].append(path)

            if is_known_patch_dump(path):
                targets["patch_dumps"].append(path)

    # The specific accidental patch dump has no normal extension and may have
    # already been matched by a generic category only if its name changes.
    patch_path = root / ("tore -- " + chr(92))
    if is_known_patch_dump(patch_path) and patch_path not in targets["patch_dumps"]:
        targets["patch_dumps"].append(patch_path)

    for key in targets:
        targets[key] = sorted(set(targets[key]))
    return targets


def python_module_name(path: Path, root: Path) -> str | None:
    relative = path.relative_to(root)
    if relative.suffix != ".py":
        return None
    parts = list(relative.with_suffix("").parts)
    if parts[-1] == "__init__":
        parts.pop()
    if not parts:
        return None
    return ".".join(parts)


def has_main_guard(tree: ast.AST) -> bool:
    for node in getattr(tree, "body", []):
        if not isinstance(node, ast.If):
            continue
        test = node.test
        if (
            isinstance(test, ast.Compare)
            and isinstance(test.left, ast.Name)
            and test.left.id == "__name__"
            and any(
                isinstance(op, ast.Eq)
                and isinstance(comp, ast.Constant)
                and comp.value == "__main__"
                for op, comp in zip(test.ops, test.comparators)
            )
        ):
            return True
    return False


def resolve_from_import(current_module: str, path: Path, node: ast.ImportFrom) -> set[str]:
    """Resolve a Python ImportFrom node to possible in-repo module names."""
    if node.level == 0:
        base = node.module or ""
    else:
        parts = current_module.split(".")
        # An __init__.py represents its package; regular modules import relative
        # to their containing package.
        is_init = path.name == "__init__.py"
        package_parts = parts if is_init else parts[:-1]
        keep = max(0, len(package_parts) - node.level + 1)
        base_parts = package_parts[:keep]
        if node.module:
            base_parts.extend(node.module.split("."))
        base = ".".join(base_parts)

    resolved: set[str] = set()
    if base:
        resolved.add(base)
    for alias in node.names:
        if alias.name == "*":
            continue
        candidate = f"{base}.{alias.name}" if base else alias.name
        resolved.add(candidate)
    return resolved


def audit_unreferenced_python(root: Path) -> tuple[list[str], list[str]]:
    """Return (unreachable modules, parse errors); never changes or deletes code."""
    source_files: list[Path] = []
    for current, filenames, _ in walk_repository(root):
        for filename in filenames:
            if filename.endswith(".py"):
                source_files.append(current / filename)

    module_to_path: dict[str, Path] = {}
    for path in source_files:
        module = python_module_name(path, root)
        if module:
            module_to_path[module] = path

    graph: dict[str, set[str]] = {name: set() for name in module_to_path}
    entrypoints: set[str] = set()
    parse_errors: list[str] = []

    for module, path in module_to_path.items():
        try:
            tree = ast.parse(path.read_text(encoding="utf-8"), filename=str(path))
        except (OSError, UnicodeError, SyntaxError) as exc:
            parse_errors.append(f"{path.relative_to(root)}: {exc}")
            continue

        if has_main_guard(tree) or "tests" in path.parts or path.name.startswith("test_"):
            entrypoints.add(module)

        for node in ast.walk(tree):
            if isinstance(node, ast.Import):
                for alias in node.names:
                    imported = alias.name
                    if imported in module_to_path:
                        graph[module].add(imported)
                    else:
                        # Also account for imports that name a package prefix.
                        for candidate in module_to_path:
                            if candidate.startswith(imported + "."):
                                graph[module].add(candidate)
            elif isinstance(node, ast.ImportFrom):
                for imported in resolve_from_import(module, path, node):
                    if imported in module_to_path:
                        graph[module].add(imported)

    reachable: set[str] = set(entrypoints)
    pending = list(entrypoints)
    while pending:
        current = pending.pop()
        for child in graph.get(current, set()):
            if child not in reachable:
                reachable.add(child)
                pending.append(child)

    # Package __init__ files are implicit imports, not standalone dead modules.
    unreachable = [
        str(module_to_path[name].relative_to(root))
        for name in sorted(module_to_path)
        if name not in reachable and module_to_path[name].name != "__init__.py"
    ]
    return unreachable, parse_errors


def format_report(root: Path, targets: dict[str, list[Path]], orphans: list[str], parse_errors: list[str]) -> str:
    def rel(items: list[Path]) -> list[str]:
        return [str(p.relative_to(root)) for p in items]

    lines = [
        f"Repository: {root}",
        "Mode: DRY RUN (no files changed)",
        "",
        "SAFE CLEANUP CANDIDATES (only applied with --apply)",
        f"  __pycache__ directories: {len(targets['cache_dirs'])}",
        f"  standalone .pyc/.pyo files: {len(targets['bytecode_files'])}",
        f"  source backup files: {len(targets['backup_files'])}",
        f"  confirmed accidental diff dumps: {len(targets['patch_dumps'])}",
        "",
        "PRESERVED BY DESIGN",
        f"  root-level .log files to archive: {len(targets['log_files'])}",
        "  yolo_mask_winners/: all masks, images, CSV reports and run data",
        "  diagnostics/, tests/, current Python source and requirements snapshots",
        "",
        "POTENTIALLY UNREFERENCED PYTHON MODULES (review only; never auto-deleted)",
    ]
    lines.extend(f"  - {item}" for item in orphans) if orphans else lines.append("  none detected")

    if parse_errors:
        lines += ["", "FILES NOT INCLUDED IN IMPORT AUDIT (parse/read errors)"]
        lines.extend(f"  - {item}" for item in parse_errors)

    for title, key in (
        ("CACHE DIRECTORIES", "cache_dirs"),
        ("STANDALONE BYTECODE", "bytecode_files"),
        ("BACKUP FILES TO ARCHIVE", "backup_files"),
        ("ACCIDENTAL DIFF DUMP TO ARCHIVE", "patch_dumps"),
    ):
        items = rel(targets[key])
        if items:
            lines += ["", title]
            lines.extend(f"  - {item}" for item in items)

    if targets["log_files"]:
        lines += ["", "ROOT-LEVEL LOGS TO ARCHIVE"]
        lines.extend(f"  - {item}" for item in rel(targets["log_files"]))

    lines += [
        "",
        "No application logic is deleted. Unreferenced-module findings are hints only:",
        "scripts may be launched manually or from outside the repository.",
    ]
    return "\n".join(lines)


def apply_cleanup(root: Path, targets: dict[str, list[Path]]) -> Path | None:
    archived_files = (
        targets["backup_files"] + targets["patch_dumps"] + targets["log_files"]
    )
    archive_dir: Path | None = None

    if archived_files:
        stamp = dt.datetime.now().strftime("%Y%m%d_%H%M%S")
        archive_dir = root.parent / f".{root.name}_cleanup_archive_{stamp}"
        # Never overwrite an earlier archive.
        archive_dir.mkdir(parents=False, exist_ok=False)
        for source in archived_files:
            relative = source.relative_to(root)
            destination = archive_dir / relative
            destination.parent.mkdir(parents=True, exist_ok=True)
            shutil.move(str(source), str(destination))

    for cache_dir in sorted(targets["cache_dirs"], key=lambda p: len(p.parts), reverse=True):
        if cache_dir.exists() and cache_dir.is_dir() and not cache_dir.is_symlink():
            shutil.rmtree(cache_dir)

    for bytecode in targets["bytecode_files"]:
        if bytecode.is_file() and not bytecode.is_symlink():
            bytecode.unlink()

    return archive_dir


def main() -> int:
    parser = argparse.ArgumentParser(
        description="Conservative cleanup of generated Python files and obsolete code backups."
    )
    parser.add_argument(
        "--apply",
        action="store_true",
        help="apply safe cleanup; backup files are archived outside the repository first",
    )
    parser.add_argument(
        "--root",
        type=Path,
        default=default_repo_root(),
        help="repository root (defaults to the parent of this script's directory)",
    )
    args = parser.parse_args()
    root = args.root.expanduser().resolve()
    if not root.is_dir():
        parser.error(f"repository root does not exist or is not a directory: {root}")

    targets = collect_cleanup_targets(root)
    orphans, parse_errors = audit_unreferenced_python(root)
    report = format_report(root, targets, orphans, parse_errors)

    if not args.apply:
        print(report)
        print("\nNothing changed. Run again with --apply to perform the safe cleanup.")
        return 0

    print(report.replace("Mode: DRY RUN (no files changed)", "Mode: APPLY"))
    archive_dir = apply_cleanup(root, targets)
    print("\nCLEANUP COMPLETE")
    print(f"  Removed cache directories: {len(targets['cache_dirs'])}")
    print(f"  Removed standalone bytecode files: {len(targets['bytecode_files'])}")
    print(f"  Archived backup/diff/log files: {len(targets['backup_files']) + len(targets['patch_dumps']) + len(targets['log_files'])}")
    if archive_dir:
        print(f"  Recovery archive: {archive_dir}")
    else:
        print("  Recovery archive: not needed")
    print("  Nested diagnostics logs, diagnostics and result images were not modified.")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())


===== train_ranker.py =====

#!/usr/bin/env python3
"""Train/evaluate a candidate ranker from hand labels (standalone, no pipeline changes).

    pip install scikit-learn pandas      # if missing in the venv
    python train_ranker.py --scores candidate_scores.csv --labels labels.csv \
        [--winner-report winner_report.csv] --out ranker_out

Outputs (in --out):
  cv_report.txt        grouped cross-validation results vs. baselines
  ranker_picks.csv     one row per image: ranker pick, confidence, review flag
  ranker.pkl           final model (trained on all usable labels)

Evaluation unit: "is the picked candidate one you marked acceptable?" measured on
images the model never saw during training (grouped K-fold, repeated).
"""
from __future__ import annotations

import argparse
import pickle
import warnings
from pathlib import Path

import numpy as np
import pandas as pd
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

warnings.filterwarnings("ignore")

CANDS = ["0", "2", "4", "6", "8", "10", "HYBRID_D2", "HYBRID_D6",
         "CONTRAST_T38", "SMART_INK", "BOX_ONLY"]
REL_COLS = [
    "text_quality_score", "score", "structure_score", "visual_text_residual_score",
    "residual_text_detail_ratio", "residual_inside_peak", "residual_inside_energy",
    "sprite_contour_displacement_ratio", "sprite_texture_distortion_ratio",
    "residual_blob_contrast_ratio", "outline_leak_score", "boundary_color_artifact_ratio",
    "max_text_anchor_retained_detail_ratio", "residual_micro_component_area",
    "external_edge_destruction_score",
]
NON_FEATURES = {"image", "distance_px", "img", "cand", "good", "none_good", "skipped"}


def stem(s: pd.Series) -> pd.Series:
    return s.astype(str).str.replace(r"\.[A-Za-z0-9]+$", "", regex=True)


def build_features(S: pd.DataFrame) -> tuple[pd.DataFrame, list[str]]:
    num = [c for c in S.columns if c not in NON_FEATURES
           and pd.api.types.is_numeric_dtype(S[c]) and S[c].nunique() > 1]
    X = S[num].fillna(0.0).copy()
    g = S["img"]
    rel = {}
    for c in REL_COLS:
        if c in X:
            v = X[c]
            rel[c + "_dmin"] = v - v.groupby(g).transform("min")
            rel[c + "_dmed"] = v - v.groupby(g).transform("median")
            rel[c + "_rank"] = v.groupby(g).rank(pct=True)
    X = pd.concat([X, pd.DataFrame(rel)], axis=1)
    for c in CANDS:
        X["is_" + c] = (S["cand"] == c).astype(int)
    return X, list(X.columns)


def make_hgb(seed=0):
    return HistGradientBoostingClassifier(max_depth=3, learning_rate=0.05, max_iter=150,
                                          l2_regularization=1.0, random_state=seed)


def make_lr():
    return make_pipeline(StandardScaler(), LogisticRegression(C=0.05, max_iter=3000))


def pick(df: pd.DataFrame, col: str) -> pd.DataFrame:
    return df.loc[df.groupby("img")[col].idxmax()]


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--scores", type=Path, required=True)
    ap.add_argument("--labels", type=Path, required=True)
    ap.add_argument("--winner-report", type=Path, help="current selector's choices (optional)")
    ap.add_argument("--out", type=Path, default=Path("ranker_out"))
    ap.add_argument("--repeats", type=int, default=8)
    a = ap.parse_args()
    a.out.mkdir(parents=True, exist_ok=True)
    rep: list[str] = []

    def say(s=""):
        print(s); rep.append(s)

    S = pd.read_csv(a.scores, encoding="utf-8-sig")
    S["img"] = stem(S["image"]); S["cand"] = S["distance_px"].astype(str)
    L = pd.read_csv(a.labels, encoding="utf-8-sig")
    L["img"] = stem(L["image"]); L["cand"] = L["candidate"].astype(str)

    X_all, feats = build_features(S)
    S = S.reset_index(drop=True)
    D = S.merge(L[["img", "cand", "good", "none_good", "skipped"]], on=["img", "cand"], how="left")
    D = D.reset_index(drop=True)
    labeled_imgs = set(L["img"])
    D["is_labeled"] = D["img"].isin(labeled_imgs)

    lab = D[D.is_labeled]
    per = lab.groupby("img").agg(g=("good", "sum"), n=("good", "count"),
                                 none=("none_good", "max"), skip=("skipped", "max"))
    usable = per[(per.g > 0) & (per.g < per.n) & (per.none == 0) & (per.skip == 0)].index
    say(f"Labeled images: {len(per)} | none-good: {int(per.none.sum())} | skipped: {int(per.skip.sum())}"
        f" | all-candidates-good: {int((per.g == per.n).sum())} | usable for ranking: {len(usable)}")
    T = D[D.img.isin(usable)].copy()
    X = X_all.loc[T.index]
    y = T["good"].astype(int).values
    imgs = T["img"].unique()

    # ---- baselines
    say("\n== Baselines on usable images (hit rate = pick is acceptable) ==")
    T["_p"] = 0.0
    for c in ["BOX_ONLY", "HYBRID_D6", "HYBRID_D2", "CONTRAST_T38", "SMART_INK"]:
        say(f"  always {c:13s}: {T[T.cand == c].good.mean():.3f}")
    say(f"  random pick         : {T.groupby('img').good.mean().mean():.3f}")
    if "score" in T:
        T["_p"] = -T["score"].values
        say(f"  lowest 'score' column (proxy for current selector): {pick(T, '_p').good.mean():.3f}")
    if a.winner_report and a.winner_report.is_file():
        W = pd.read_csv(a.winner_report, encoding="utf-8-sig")
        W["img"] = stem(W["image"]); W["cand"] = W["selected_distance_px"].astype(str)
        M = W[["img", "cand"]].merge(T[["img", "cand", "good"]], on=["img", "cand"], how="inner")
        say(f"  ACTUAL current selector (winner_report): {M.good.mean():.3f}  (n={len(M)})")

    # ---- grouped CV, repeated
    say(f"\n== Grouped cross-validation ({a.repeats}x 5-fold, images never seen in training) ==")
    results = {"hgb": [], "lr": [], "blend": []}
    oof_sum = np.zeros(len(T))
    for seed in range(a.repeats):
        rng = np.random.RandomState(seed)
        fold_of = {i: rng.randint(0, 5) for i in imgs}
        fold = T["img"].map(fold_of).values
        ph, pl = np.zeros(len(T)), np.zeros(len(T))
        for f in range(5):
            tr, te = fold != f, fold == f
            m1 = make_hgb(seed).fit(X[tr], y[tr]); m2 = make_lr().fit(X[tr], y[tr])
            ph[te] = m1.predict_proba(X[te])[:, 1]; pl[te] = m2.predict_proba(X[te])[:, 1]
        for name, p in (("hgb", ph), ("lr", pl), ("blend", (ph + pl) / 2)):
            T["_p"] = p
            results[name].append(pick(T, "_p").good.mean())
        oof_sum += (ph + pl) / 2
    for k, v in results.items():
        say(f"  {k:6s}: {np.mean(v):.3f} +/- {np.std(v):.3f}")
    say("  (with ~%d images, differences under ~2 points are within noise)" % len(imgs))

    # ---- confidence vs accuracy (out-of-fold)
    T["_p"] = oof_sum / a.repeats
    top = pick(T, "_p").copy()
    sec = T.sort_values("_p", ascending=False).groupby("img")["_p"].nth(1)
    top["margin"] = top["_p"].values - sec.reindex(top["img"]).values
    say("\n== Out-of-fold confidence vs. hit rate (use to set the review threshold) ==")
    top["bucket"] = pd.qcut(top["_p"], 4, duplicates="drop")
    for b, d in top.groupby("bucket", observed=True):
        say(f"  top prob {b}: hit {d.good.mean():.3f}  (n={len(d)})")
    thr = float(top["_p"].quantile(0.25))
    keep = top[top["_p"] >= thr]
    say(f"  auto-accept above top-prob {thr:.2f}: hit {keep.good.mean():.3f} on {len(keep)}/{len(top)} images;"
        f" the rest ({len(top) - len(keep)}) go to review")

    # ---- does the ranker's confidence flag the CURRENT selector's mistakes?
    if a.winner_report and a.winner_report.is_file():
        sel = M.rename(columns={"good": "sel_good"})[["img", "sel_good"]]
        chk = top[["img", "_p"]].merge(sel, on="img", how="inner")
        chk["flagged"] = chk["_p"] < thr
        miss = chk[chk.sel_good == 0]
        say("\n== Using ranker confidence as a review flag on the CURRENT selector ==")
        say(f"  selector misses: {len(miss)} of {len(chk)} images")
        for flag, d in chk.groupby("flagged"):
            say(f"  {'flagged (low confidence)' if flag else 'not flagged':24s}: "
                f"selector hit {d.sel_good.mean():.3f}  (n={len(d)})")
        caught = int(miss.flagged.sum())
        say(f"  misses caught by the flag: {caught}/{len(miss)}"
            f"  | reviewing {int(chk.flagged.sum())} of {len(chk)} images"
            f" ({chk.flagged.mean():.0%})")
        for q in (0.15, 0.35, 0.5):
            t2 = float(top["_p"].quantile(q)); f2 = chk["_p"] < t2
            say(f"  flag lowest {int(q*100):2d}% by confidence: catches "
                f"{int(miss['_p'].lt(t2).sum())}/{len(miss)} misses, reviews {int(f2.sum())} images")

    # ---- final model on all usable labels, predict every image
    m1 = make_hgb(0).fit(X, y); m2 = make_lr().fit(X, y)
    D["_p"] = (m1.predict_proba(X_all)[:, 1] + m2.predict_proba(X_all)[:, 1]) / 2
    rows = []
    for img, d in D.groupby("img"):
        d = d.sort_values("_p", ascending=False)
        best = d.iloc[0]
        rows.append({
            "image": img + ".png", "ranker_pick": best["cand"], "top_prob": round(best["_p"], 4),
            "runner_up": d.iloc[1]["cand"], "runner_up_prob": round(d.iloc[1]["_p"], 4),
            "needs_review": int(best["_p"] < thr),
            "already_labeled": int(img in labeled_imgs),
        })
    P = pd.DataFrame(rows)
    if a.winner_report and a.winner_report.is_file():
        W2 = W[["image", "selected_distance_px"]].rename(columns={"selected_distance_px": "current_pick"})
        P = P.merge(W2, on="image", how="left")
        P["differs_from_current"] = (P["ranker_pick"].astype(str) != P["current_pick"].astype(str)).astype(int)
    P.to_csv(a.out / "ranker_picks.csv", index=False, encoding="utf-8-sig")
    with (a.out / "ranker.pkl").open("wb") as f:
        pickle.dump({"features": feats, "hgb": m1, "lr": m2, "review_threshold": thr}, f)
    say(f"\nWrote {a.out/'ranker_picks.csv'} ({len(P)} images; {int(P.needs_review.sum())} flagged for review)")
    (a.out / "cv_report.txt").write_text("\n".join(rep), encoding="utf-8")


if __name__ == "__main__":
    main()

===== yolo_mask_auto_select_modules/candidate_masks.py =====

"""Single source of truth for all candidate masks of one image.

Every candidate mask (YOLO distances, hybrids, contrast, smart-ink, box-only) and every
reference mask used for scoring is built here, with the protected zones already
subtracted. LaMa staging, compositing and scoring all use this one result, so the mask
LaMa inpaints is always the mask that is composited and scored.
"""
from __future__ import annotations

from dataclasses import dataclass, field
from typing import Any

import numpy as np

from .geometry import protected_mask
from .io_utils import make_box_only_mask
from .scoring import make_contrast_mask, make_smart_ink_mask

HYBRID_DISTANCES = (2, 6)


@dataclass
class ImageMaskSet:
    candidates: dict[int | str, np.ndarray]
    box_mask: np.ndarray
    smart_mask: np.ndarray
    body_box_mask: np.ndarray
    yolo_reference_mask: np.ndarray
    scoring_envelope: np.ndarray
    protected: np.ndarray
    zones: list[dict[str, Any]] = field(default_factory=list)


def stage_token(candidate_id: int | str) -> str:
    """File-name token used when staging a candidate for LaMa (unchanged naming)."""
    if isinstance(candidate_id, int):
        return f"d{candidate_id:02d}"
    if candidate_id.startswith("HYBRID_D"):
        return f"hybrid_d{int(candidate_id[len('HYBRID_D'):]):02d}"
    return candidate_id.lower()


def build_image_mask_set(
    *,
    rgb: np.ndarray,
    alpha: np.ndarray,
    boxes: list[dict[str, Any]],
    zones: list[dict[str, Any]],
    yolo_masks: dict[int, np.ndarray],
    box_only_mask: np.ndarray,
    contrast_thresholds: tuple[float, ...],
    contrast_candidate_ids: list[str],
    protected_margin_px: int = 0,
) -> ImageMaskSet:
    height, width = rgb.shape[:2]
    protected = protected_mask(zones, width, height, protected_margin_px)
    has_protection = bool(protected.any())

    def prot(mask: np.ndarray) -> np.ndarray:
        mask = np.asarray(mask) > 0
        return mask & ~protected if has_protection else mask

    masks = {d: prot(m) for d, m in yolo_masks.items()}
    box_mask = prot(box_only_mask)
    smart_mask = prot(make_smart_ink_mask(rgb, boxes))
    body_boxes = [b for b in boxes if str(b.get("type", "")).casefold() == "body"]
    body_box_mask = prot(make_box_only_mask(width, height, body_boxes))

    candidates: dict[int | str, np.ndarray] = dict(sorted(masks.items()))
    for d in HYBRID_DISTANCES:
        candidates[f"HYBRID_D{d}"] = box_mask | masks[d]
    for threshold, candidate_id in zip(contrast_thresholds, contrast_candidate_ids):
        candidates[candidate_id] = prot(make_contrast_mask(rgb, alpha, boxes, threshold))
    candidates["SMART_INK"] = smart_mask
    candidates["BOX_ONLY"] = box_mask

    yolo_reference = masks[max(masks)]
    return ImageMaskSet(
        candidates=candidates,
        box_mask=box_mask,
        smart_mask=smart_mask,
        body_box_mask=body_box_mask,
        yolo_reference_mask=yolo_reference,
        scoring_envelope=yolo_reference | box_mask | smart_mask,
        protected=protected,
        zones=zones,
    )


def enforce_protection(
    final_rgb: np.ndarray, final_alpha: np.ndarray,
    original_rgb: np.ndarray, original_alpha: np.ndarray,
    protected: np.ndarray,
) -> dict[str, float]:
    """Hard guarantee: protected pixels are restored to the original (in place).

    Returns metrics; ``protected_pixels_restored`` > 0 means some earlier step touched a
    protected pixel (a bug worth investigating) - the pixels are restored regardless.
    """
    count = int(np.count_nonzero(protected))
    if not count:
        return {"protected_pixels": 0.0, "protected_pixels_restored": 0.0}
    differs = (final_rgb != original_rgb).any(axis=-1) | (final_alpha != original_alpha)
    restored = int(np.count_nonzero(differs & protected))
    final_rgb[protected] = original_rgb[protected]
    final_alpha[protected] = original_alpha[protected]
    return {"protected_pixels": float(count), "protected_pixels_restored": float(restored)}

"""Debug image generation: cleaned candidates, mask overlays and paired previews."""
from __future__ import annotations

import math
from typing import Any

import numpy as np
from PIL import Image, ImageDraw, ImageFont

def _pillow_safe_label(label: str) -> str:
    """Keep debug labels printable with Pillow's built-in bitmap font (Latin-1)."""
    replacements = {
        "—": "-", "–": "-", "−": "-", "→": "->",
        "≤": "<=", "≥": ">=", "×": "x", "…": "...",
    }
    for source, replacement in replacements.items():
        label = label.replace(source, replacement)
    try:
        label.encode("latin-1")
    except UnicodeEncodeError:
        label = label.encode("latin-1", errors="replace").decode("latin-1")
    return label

def save_debug_contact_sheet(
    original_rgba: np.ndarray,
    items: list[tuple[str, np.ndarray]],
    output_path: Path,
    *,
    tile_width: int = 420,
    tile_height: int = 340,
) -> None:
    """Write a contact sheet containing only finished images, never masks.

    RGBA images are composited over a subtle checkerboard for previewing alpha.
    The individual PNGs preserve source alpha outside the mask and use LaMa's
    alpha reconstruction inside the mask.
    """
    if not items:
        return

    def preview_rgb(array: np.ndarray) -> Image.Image:
        arr = np.asarray(array, dtype=np.uint8)
        if arr.ndim == 2:
            return Image.fromarray(arr, mode="L").convert("RGB")
        if arr.shape[2] == 3:
            return Image.fromarray(arr, mode="RGB")
        if arr.shape[2] != 4:
            raise ValueError(f"Unsupported debug image shape: {arr.shape}")
        foreground = Image.fromarray(arr, mode="RGBA")
        alpha = foreground.getchannel("A")
        w, h = foreground.size
        tile = 16
        checker = Image.new("RGB", (w, h), (238, 238, 238))
        draw = ImageDraw.Draw(checker)
        for y in range(0, h, tile):
            for x in range(0, w, tile):
                if ((x // tile) + (y // tile)) % 2:
                    draw.rectangle((x, y, min(x + tile - 1, w - 1), min(y + tile - 1, h - 1)), fill=(205, 205, 205))
        checker.paste(foreground.convert("RGB"), mask=alpha)
        return checker

    all_items = [("Original", original_rgba), *items]
    columns = 3
    rows = math.ceil(len(all_items) / columns)
    label_height = 30
    canvas = Image.new("RGB", (columns * tile_width, rows * (tile_height + label_height)), "white")
    draw = ImageDraw.Draw(canvas)
    font = ImageFont.load_default()

    for index, (label, array) in enumerate(all_items):
        col = index % columns
        row = index // columns
        x0 = col * tile_width
        y0 = row * (tile_height + label_height)
        is_winner = "[WINNER]" in label.upper()

        # Make the selected candidate visible at thumbnail size, not just in text.
        cell_box = (x0 + 2, y0 + 2, x0 + tile_width - 3, y0 + tile_height + label_height - 3)
        if is_winner:
            draw.rectangle((x0, y0, x0 + tile_width - 1, y0 + label_height - 1), fill=(255, 225, 110))
            draw.rectangle(cell_box, outline=(235, 125, 20), width=5)
            label = "WINNER | " + label.replace("[WINNER]", "").strip(" |-")
        draw.text((x0 + 8, y0 + 7), _pillow_safe_label(label), fill="black", font=font)
        tile = preview_rgb(array)
        tile.thumbnail((tile_width - 16, tile_height - 12), Image.Resampling.LANCZOS)
        px = x0 + (tile_width - tile.width) // 2
        py = y0 + label_height + (tile_height - tile.height) // 2
        canvas.paste(tile, (px, py))
        if is_winner:
            draw.rectangle(cell_box, outline=(235, 125, 20), width=5)

    output_path.parent.mkdir(parents=True, exist_ok=True)
    canvas.save(output_path, quality=92)

def _draw_outline(draw: ImageDraw.ImageDraw, box: dict[str, Any], width: int, height: int,
                  color: tuple[int, int, int]) -> None:
    """Outline a box: polygon if the box has one, else its rectangle."""
    poly_value = box.get("poly")
    if poly_value is not None:
        polygons = [poly_value] if isinstance(poly_value, np.ndarray) else poly_value
        for poly in polygons:
            pts = [(float(x), float(y)) for x, y in poly]
            if len(pts) >= 3:
                draw.line(pts + [pts[0]], fill=color, width=2)
        return
    try:
        x1 = max(0, min(width - 1, int(round(float(box["x1"])))))
        y1 = max(0, min(height - 1, int(round(float(box["y1"])))))
        x2 = max(0, min(width - 1, int(round(float(box["x2"])))))
        y2 = max(0, min(height - 1, int(round(float(box["y2"])))))
    except (KeyError, TypeError, ValueError):
        return
    if x2 < x1 or y2 < y1:
        return
    draw.rectangle((x1, y1, x2, y2), outline=color, width=2)

def build_debug_mask_overlay(
    original_rgb: np.ndarray,
    candidate_mask: np.ndarray,
    boxes: list[dict[str, Any]],
    zones: list[dict[str, Any]] | None = None,
) -> np.ndarray:
    """Render a magenta candidate-mask tint over raw RGB and outline OCR boxes.

    Body boxes are red; header boxes are violet; boxes with a polygon are drawn as
    polygons. Protected zones (optional) are outlined in blue. The image is RGB (not
    RGBA) so the mask tint remains visible even where the source alpha is transparent.
    """
    base = np.asarray(original_rgb, dtype=np.float32).copy()
    selected = np.asarray(candidate_mask).astype(bool)
    tint = np.array([255.0, 35.0, 185.0], dtype=np.float32)
    base[selected] = base[selected] * 0.48 + tint * 0.52
    overlay = Image.fromarray(np.clip(base, 0, 255).astype(np.uint8), mode="RGB")
    draw = ImageDraw.Draw(overlay)
    width, height = overlay.size
    for box in boxes:
        box_type = str(box.get("type", "")).casefold()
        color = (225, 45, 45) if box_type == "body" else ((170, 90, 215) if box_type == "header" else (255, 170, 0))
        _draw_outline(draw, box, width, height, color)
    for zone in zones or []:
        _draw_outline(draw, zone, width, height, (30, 90, 255))
    return np.asarray(overlay, dtype=np.uint8)

===== yolo_mask_auto_select_modules/fill_repair.py =====

"""Post-fill sanity check for inpainting results (LaMa).

Finds clusters inside the candidate mask where the LaMa fill disagrees strongly
with a deterministic fill (cv2 Navier-Stokes) AND where the local surrounding is
flat. Only such clusters are replaced by the deterministic fill. Clusters next to
frames/outlines/textures are left untouched (LaMa is better there).
"""
from __future__ import annotations

import cv2
import numpy as np
from scipy import ndimage as ndi


def repair_flat_fill_artifacts(
    original_rgb: np.ndarray,
    filled_rgb: np.ndarray,
    mask: np.ndarray,
    protected: np.ndarray | None = None,
    *,
    min_cluster_px: int = 25,
    disagree_levels: int = 45,
    flat_ring_std: float = 20.0,
    ring_inner: int = 2,
    ring_outer: int = 6,
    grow_px: int = 2,
    inpaint_radius: int = 4,
) -> tuple[np.ndarray, dict[str, float]]:
    """Return (repaired_rgb, meta). Inputs are uint8 HxWx3 and a bool HxW mask."""
    mask = mask.astype(bool)
    meta = {"fill_repair_clusters_found": 0.0, "fill_repair_clusters_repaired": 0.0,
            "fill_repair_pixels_replaced": 0.0}
    if not mask.any():
        return filled_rgb, meta

    ns = cv2.inpaint(np.ascontiguousarray(original_rgb), mask.astype(np.uint8) * 255,
                     inpaint_radius, cv2.INPAINT_NS)
    diff = np.abs(filled_rgb.astype(np.int16) - ns.astype(np.int16)).max(axis=2)
    seeds = ndi.binary_opening((diff > disagree_levels) & mask, iterations=1)
    labels, count = ndi.label(seeds)

    out = filled_rgb.copy()
    for idx in range(1, count + 1):
        cluster = labels == idx
        if int(cluster.sum()) < min_cluster_px:
            continue
        meta["fill_repair_clusters_found"] += 1
        ring = (ndi.binary_dilation(cluster, iterations=ring_outer)
                & ~ndi.binary_dilation(cluster, iterations=ring_inner))
        ring_px = filled_rgb[ring].astype(np.float32)
        if ring_px.shape[0] < 20 or float(ring_px.std(axis=0).max()) > flat_ring_std:
            continue  # not flat around the cluster: leave LaMa result alone
        med = np.median(ring_px, axis=0)
        lama_dev = np.abs(filled_rgb[cluster].astype(np.float32) - med).max(axis=1).mean()
        ns_dev = np.abs(ns[cluster].astype(np.float32) - med).max(axis=1).mean()
        if ns_dev * 2.0 > lama_dev:
            continue  # deterministic fill is not clearly closer to the surroundings
        region = ndi.binary_dilation(cluster, iterations=grow_px) & mask
        if protected is not None:
            region &= ~protected.astype(bool)
        out[region] = ns[region]
        meta["fill_repair_clusters_repaired"] += 1
        meta["fill_repair_pixels_replaced"] += float(region.sum())
    return out, meta

"""Shared geometry: polygon anchors (instead of plain boxes) and protected zones.

Used by the pipeline, the scoring module and the routing audit so that all of them
rasterise anchors and protected zones in exactly the same way.

Box dictionaries keep their rectangle (``x1..y2``). If a usable polygon exists, it is
stored under ``"poly"`` (float array, shape (N, 2)); axis-aligned rectangles are
stored as plain boxes with ``poly=None`` so the historic rectangle code path and its
pixel semantics (inclusive floor/ceil rectangle) stay untouched.
"""
from __future__ import annotations

import csv
import math
import sys
from collections import defaultdict
from pathlib import Path
from typing import Any

import cv2
import numpy as np

from .config import (
    PROTECTED_ZONES_FILENAME,
    USE_BODY_MASK_POLYGONS,
    USE_HEADER_POLYGONS,
)


def resolve_protected_zones_csv(
    anchors_path: Path,
    explicit_path: Path | None = None,
) -> Path | None:
    """Resolve an explicit protected-zones CSV or discover it beside anchors.csv.

    An explicit path is returned even when it does not exist so the subsequent
    CSV reader can raise a clear FileNotFoundError. Without an explicit path,
    protected_zones.csv is optional and is only returned when present next to
    the selected anchors CSV.
    """
    if explicit_path is not None:
        return explicit_path.expanduser().resolve()
    candidate = anchors_path.expanduser().resolve().with_name(PROTECTED_ZONES_FILENAME)
    return candidate if candidate.is_file() else None


def parse_polygon(text: str | None) -> np.ndarray | None:
    """Parse ``"x,y;x,y;..."``. Returns None for empty or invalid input."""
    if not text or not str(text).strip():
        return None
    try:
        pts = [tuple(float(v) for v in part.split(",")) for part in str(text).split(";") if part.strip()]
        arr = np.asarray(pts, dtype=np.float64)
    except ValueError:
        return None
    if arr.ndim != 2 or arr.shape[0] < 3 or arr.shape[1] != 2 or not np.isfinite(arr).all():
        return None
    return arr


def _is_axis_aligned_rect(poly: np.ndarray) -> bool:
    return (
        poly.shape[0] == 4
        and len(set(poly[:, 0].tolist())) == 2
        and len(set(poly[:, 1].tolist())) == 2
    )


def parse_polygons(text: str | None) -> list[np.ndarray] | None:
    """Parse Yabai mask_polygon; disconnected components are separated by '|'."""
    if not text or not str(text).strip():
        return None
    pieces = [piece.strip() for piece in str(text).split('|')]
    if not pieces or any(not piece for piece in pieces):
        return None
    polygons: list[np.ndarray] = []
    for piece in pieces:
        polygon = parse_polygon(piece)
        if polygon is None:
            return None
        polygons.append(polygon)
    return polygons


def anchor_polygon(row: dict[str, Any]) -> np.ndarray | list[np.ndarray] | None:
    """Return white cleaning geometry; None means use the red rectangle fallback.

    Body anchors use ONLY mask_polygon. The separate polygon field is the
    original OCR contour and must not replace the red box if the white mask is absent.
    Header anchors continue to use their rotated OCR polygon.
    """
    kind = str(row.get("type") or "").strip().casefold()
    if kind == "body":
        if not USE_BODY_MASK_POLYGONS:
            return None
        polygons = parse_polygons(row.get("mask_polygon"))
        if not polygons:
            return None
        if len(polygons) == 1 and _is_axis_aligned_rect(polygons[0]):
            return None
        return polygons[0] if len(polygons) == 1 else polygons

    if not USE_HEADER_POLYGONS:
        return None
    poly = parse_polygon(row.get("polygon"))
    if poly is None or _is_axis_aligned_rect(poly):
        return None
    return poly



def box_region(box: dict[str, Any], width: int, height: int) -> tuple[int, int, int, int, np.ndarray] | None:
    """Return ``(x1, y1, x2, y2, crop_mask)`` with inclusive pixel bounds.

    ``crop_mask`` is a bool array of shape ``(y2-y1+1, x2-x1+1)``. Rectangles use the
    historic floor/ceil clamp; polygons use rounded vertices clamped to the image.
    """
    poly_value = box.get("poly")
    if poly_value is None:
        try:
            x1 = max(0, min(width - 1, math.floor(float(box["x1"]))))
            y1 = max(0, min(height - 1, math.floor(float(box["y1"]))))
            x2 = max(0, min(width - 1, math.ceil(float(box["x2"]))))
            y2 = max(0, min(height - 1, math.ceil(float(box["y2"]))))
        except (KeyError, TypeError, ValueError, OverflowError):
            return None
        if x2 < x1 or y2 < y1:
            return None
        return x1, y1, x2, y2, np.ones((y2 - y1 + 1, x2 - x1 + 1), dtype=bool)

    raw_polygons = [poly_value] if isinstance(poly_value, np.ndarray) else list(poly_value)
    if not raw_polygons:
        return None
    points: list[np.ndarray] = []
    for raw_poly in raw_polygons:
        pts = np.rint(np.asarray(raw_poly, dtype=np.float64)).astype(np.int32)
        if pts.ndim != 2 or pts.shape[0] < 3 or pts.shape[1] != 2:
            return None
        pts[:, 0] = np.clip(pts[:, 0], 0, width - 1)
        pts[:, 1] = np.clip(pts[:, 1], 0, height - 1)
        points.append(pts)
    all_points = np.concatenate(points, axis=0)
    x1, y1 = int(all_points[:, 0].min()), int(all_points[:, 1].min())
    x2, y2 = int(all_points[:, 0].max()), int(all_points[:, 1].max())
    crop = np.zeros((y2 - y1 + 1, x2 - x1 + 1), dtype=np.uint8)
    offset = np.array([x1, y1], dtype=np.int32)
    cv2.fillPoly(crop, [pts - offset for pts in points], 255)
    return x1, y1, x2, y2, crop > 0


def box_mask(box: dict[str, Any], width: int, height: int) -> np.ndarray:
    """Full-image bool mask of one anchor (polygon if present, else rectangle)."""
    out = np.zeros((height, width), dtype=bool)
    region = box_region(box, width, height)
    if region is not None:
        x1, y1, x2, y2, crop = region
        out[y1:y2 + 1, x1:x2 + 1] |= crop
    return out


def boxes_union_mask(boxes: list[dict[str, Any]], width: int, height: int) -> np.ndarray:
    out = np.zeros((height, width), dtype=bool)
    for box in boxes:
        region = box_region(box, width, height)
        if region is not None:
            x1, y1, x2, y2, crop = region
            out[y1:y2 + 1, x1:x2 + 1] |= crop
    return out


def inset_region(crop: np.ndarray, inset_x: int, inset_y: int) -> np.ndarray:
    """Erode a region mask by (inset_x, inset_y) pixels; fall back to the full region if it vanishes."""
    h, w = crop.shape
    padded = np.pad(crop.astype(np.uint8), ((inset_y, inset_y), (inset_x, inset_x)))
    kernel = np.ones((2 * inset_y + 1, 2 * inset_x + 1), dtype=np.uint8)
    eroded = cv2.erode(padded, kernel)[inset_y:inset_y + h, inset_x:inset_x + w] > 0
    return eroded if eroded.any() else crop

def read_protected_zones(path: Path) -> dict[str, list[dict[str, Any]]]:
    """Read ``protected_zones.csv`` -> ``{image_name: [zone_box, ...]}``.

    Required column: ``image``. Geometry from ``polygon`` or, if missing/invalid, from
    ``x1,y1,x2,y2``. Invalid rows are skipped with a warning.
    """
    if not path.is_file():
        raise FileNotFoundError(f"protected zones CSV not found: {path}")
    by_image: dict[str, list[dict[str, Any]]] = defaultdict(list)
    with path.open("r", encoding="utf-8-sig", newline="") as f:
        reader = csv.DictReader(f)
        if "image" not in (reader.fieldnames or []):
            raise ValueError("protected zones CSV missing column: image")
        for n, row in enumerate(reader, start=2):
            name = Path((row.get("image") or "").strip()).name
            if not name:
                continue
            poly = parse_polygon(row.get("polygon"))
            try:
                if poly is not None:
                    x1, y1 = poly.min(axis=0)
                    x2, y2 = poly.max(axis=0)
                else:
                    x1, y1, x2, y2 = (float(row[k]) for k in ("x1", "y1", "x2", "y2"))
                if not all(math.isfinite(v) for v in (x1, y1, x2, y2)) or x2 < x1 or y2 < y1:
                    raise ValueError
            except (KeyError, TypeError, ValueError):
                print(f"WARN: invalid protected zone at CSV row {n}; ignored", file=sys.stderr)
                continue
            if poly is not None and _is_axis_aligned_rect(poly):
                poly = None
            by_image[name].append({
                "zone_id": (row.get("zone_id") or "").strip(),
                "text": (row.get("text") or "").strip(),
                "x1": float(x1), "y1": float(y1), "x2": float(x2), "y2": float(y2),
                "poly": poly,
            })
    return dict(by_image)


def protected_mask(zones: list[dict[str, Any]], width: int, height: int, margin_px: int = 0) -> np.ndarray:
    """Full-image bool mask of all protected zones, optionally grown by ``margin_px``."""
    mask = boxes_union_mask(zones, width, height)
    if margin_px > 0 and mask.any():
        k = margin_px * 2 + 1
        mask = cv2.dilate(mask.astype(np.uint8), np.ones((k, k), dtype=np.uint8)) > 0
    return mask

def choose_random_sample(
    available_names: set[str], sample_count: int, min_m_count: int, seed: int
) -> list[str]:
    """Choose a reproducible sample with at least min_m_count M-series images.

    When enough non-M images are available, the remaining slots are drawn from
    other series so the test is not dominated by M-series pages.
    """
    names = sorted(available_names, key=str.casefold)
    if sample_count <= 0:
        raise ValueError("--random-sample must be greater than zero")
    if sample_count > len(names):
        raise ValueError(f"Requested {sample_count} random images, but only {len(names)} anchor images are available")
    if min_m_count < 0 or min_m_count > sample_count:
        raise ValueError("--min-m-images must be between 0 and --random-sample")

    m_names = [name for name in names if Path(name).stem.casefold().startswith("m")]
    non_m_names = [name for name in names if name not in set(m_names)]
    if len(m_names) < min_m_count:
        raise ValueError(
            f"Need at least {min_m_count} M-series images, but anchors.csv contains only {len(m_names)}"
        )

    rng = random.Random(seed)
    chosen_m = rng.sample(m_names, min_m_count)
    slots_left = sample_count - len(chosen_m)

    if len(non_m_names) >= slots_left:
        chosen_other = rng.sample(non_m_names, slots_left)
    else:
        chosen_other = list(non_m_names)
        extra_slots = slots_left - len(chosen_other)
        remaining_m = [name for name in m_names if name not in set(chosen_m)]
        if extra_slots > len(remaining_m):
            raise ValueError("Not enough distinct images to complete the requested sample")
        chosen_other.extend(rng.sample(remaining_m, extra_slots))

    chosen = chosen_m + chosen_other
    rng.shuffle(chosen)
    return chosen

def image_name_from(row: dict[str, str]) -> str:
    return Path((row.get("image") or "").strip()).name

def read_anchor_csv(path: Path) -> tuple[list[str], list[dict[str, str]], dict[str, list[dict[str, Any]]]]:
    if not path.is_file():
        raise FileNotFoundError(f"anchors CSV not found: {path}")
    with path.open("r", encoding="utf-8-sig", newline="") as f:
        reader = csv.DictReader(f)
        fieldnames = list(reader.fieldnames or [])
        required = {"image", "type", "x1", "y1", "x2", "y2"}
        missing = required - set(fieldnames)
        if missing:
            raise ValueError("anchors CSV missing columns: " + ", ".join(sorted(missing)))
        rows = list(reader)
    by_image: dict[str, list[dict[str, Any]]] = defaultdict(list)
    for n, row in enumerate(rows, start=2):
        name = image_name_from(row)
        if not name:
            continue
        try:
            coords = [float(row[k]) for k in ("x1", "y1", "x2", "y2")]
            x1, y1, x2, y2 = coords
            if not all(math.isfinite(v) for v in coords) or x2 <= x1 or y2 <= y1:
                continue
        except (KeyError, TypeError, ValueError):
            print(f"WARN: invalid anchor coordinates at CSV row {n}; ignored", file=sys.stderr)
            continue
        by_image[name].append({
            "type": (row.get("type") or "").strip().casefold(),
            "x1": x1, "y1": y1, "x2": x2, "y2": y2,
            "poly": anchor_polygon(row),
        })
    if not by_image:
        raise ValueError(f"No valid anchor boxes found in {path}")
    return fieldnames, rows, dict(by_image)

def discover_sources(images_dir: Path, names: set[str], project: Path) -> dict[str, Path]:
    # Match the routing-audit script: the configured image collection is authoritative.
    # Do not also scan Cleanup/raw, because it may intentionally contain duplicate
    # copies of images selected from the larger source collection.
    found: dict[str, list[Path]] = defaultdict(list)
    root = images_dir.expanduser().resolve()
    if not root.is_dir():
        raise FileNotFoundError(f"Source image directory not found: {root}")
    for path in root.rglob("*"):
        if path.is_file() and path.suffix.lower() in IMAGE_EXTS and path.name in names:
            found[path.name].append(path)
    missing = sorted(names - set(found))
    duplicates = {name: paths for name, paths in found.items() if len(paths) > 1}
    if missing:
        raise FileNotFoundError(
            f"Could not locate {len(missing)} source image(s): {', '.join(missing[:12])}. "
            f"Check --images-dir ({images_dir})."
        )
    if duplicates:
        detail = "; ".join(f"{name}: {len(paths)} files" for name, paths in list(duplicates.items())[:8])
        raise ValueError("Ambiguous source image basenames; refusing to guess: " + detail)
    return {name: paths[0] for name, paths in found.items()}

def find_iopaint() -> str:
    candidate = Path(sys.executable).absolute().with_name("iopaint")
    if candidate.is_file() and os.access(candidate, os.X_OK):
        return str(candidate)
    found = shutil.which("iopaint")
    if found:
        return found
    raise FileNotFoundError(
        f"IOPaint was not found beside Python ({candidate}) or on PATH. "
        "Activate Cleanup/.venv before running this script."
    )

def choose_output_dir(path: Path, project: Path) -> Path:
    resolved = path.expanduser().resolve()
    for protected in (project / "raw", project / "cleaned", project / ".venv"):
        protected = protected.resolve()
        if resolved == protected or protected in resolved.parents:
            raise ValueError(f"Output may not be inside protected folder {protected}")
    if resolved.exists() and any(resolved.iterdir()):
        stamp = time.strftime("run_%Y%m%d_%H%M%S")
        candidate = resolved / stamp
        n = 1
        while candidate.exists():
            candidate = resolved / f"{stamp}_{n}"
            n += 1
        return candidate
    return resolved

def make_box_only_mask(width: int, height: int, boxes: list[dict[str, Any]]) -> np.ndarray:
    """Union of all anchors as uint8 0/255 mask (same rasterisation as the routing audit).

    Boxes with a ``"poly"`` entry are filled as polygons, all others as inclusive
    rectangles (floor/ceil), exactly as before.
    """
    mask = np.zeros((height, width), dtype=np.uint8)
    for box in boxes:
        region = box_region(box, width, height)
        if region is None:
            continue
        x1, y1, x2, y2, crop = region
        mask[y1:y2 + 1, x1:x2 + 1][crop] = 255
    return mask

def remove_small_alpha_islands(
    rgb: np.ndarray, alpha: np.ndarray, source_alpha: np.ndarray,
    protected: np.ndarray | None = None,
) -> tuple[np.ndarray, np.ndarray, dict[str, float]]:
    """Remove tiny disconnected visible-alpha components for transparent-canvas sprites.

    Activation is based on the SOURCE image, not the candidate output, so every
    distance candidate for the same image follows the same rule. The transparency
    ratio counts source pixels whose alpha is <= ALPHA_VISIBILITY_THRESHOLD.
    Components are 8-connected; any isolated visible component up to the configured
    size is made fully transparent. RGB is set to zero at removed pixels to avoid
    leaving hidden colour data behind.

    Components that touch a ``protected`` pixel are never removed.
    """
    transparent_ratio = float(np.mean(source_alpha <= ALPHA_VISIBILITY_THRESHOLD))
    metadata = {
        "source_transparent_ratio": transparent_ratio,
        "alpha_small_object_removal_applied": 0.0,
        "alpha_small_components_removed": 0.0,
        "alpha_small_pixels_removed": 0.0,
    }
    if (not POSTPROCESS_REMOVE_SMALL_ALPHA_ISLANDS
            or transparent_ratio < ALPHA_SMALL_OBJECT_MIN_TRANSPARENT_RATIO):
        return rgb, alpha, metadata

    visible = (alpha > ALPHA_VISIBILITY_THRESHOLD).astype(np.uint8)
    component_count, labels, stats, _centroids = cv2.connectedComponentsWithStats(visible, connectivity=8)
    remove = np.zeros(visible.shape, dtype=bool)
    removed_components = 0
    touches_protected: set[int] = (
        {int(v) for v in np.unique(labels[protected])} if protected is not None and protected.any() else set()
    )
    for label in range(1, component_count):
        area = int(stats[label, cv2.CC_STAT_AREA])
        if area <= ALPHA_SMALL_OBJECT_MAX_PIXELS and label not in touches_protected:
            remove |= labels == label
            removed_components += 1

    if removed_components:
        rgb_out = rgb.copy()
        alpha_out = alpha.copy()
        rgb_out[remove] = 0
        alpha_out[remove] = 0
    else:
        rgb_out, alpha_out = rgb, alpha

    metadata.update({
        "alpha_small_object_removal_applied": 1.0,
        "alpha_small_components_removed": float(removed_components),
        "alpha_small_pixels_removed": float(np.count_nonzero(remove)),
    })
    return rgb_out, alpha_out, metadata

"""CSV report helpers with forward-compatible columns."""
from __future__ import annotations

import csv
from pathlib import Path
from typing import Any, Iterable, Mapping, Sequence


def write_csv_with_union_fields(
    path: Path,
    rows: Sequence[Mapping[str, Any]],
    preferred_fields: Sequence[str] | None = None,
) -> list[str]:
    """Write rows using preferred column order plus every observed field.

    This deliberately avoids DictWriter's `fields not in fieldnames` failure when
    newly added metrics appear in candidate dictionaries. No fields are discarded.
    """
    columns: list[str] = []
    seen: set[str] = set()
    for key in [*(preferred_fields or ()), *(key for row in rows for key in row.keys())]:
        key = str(key)
        if key not in seen:
            seen.add(key)
            columns.append(key)
    path.parent.mkdir(parents=True, exist_ok=True)
    with path.open("w", encoding="utf-8-sig", newline="") as f:
        writer = csv.DictWriter(f, fieldnames=columns, extrasaction="raise")
        writer.writeheader()
        writer.writerows(rows)
    return columns

"""Image-based quality metrics and two-stage candidate selection."""
from __future__ import annotations

import math
from typing import Any

import cv2
import numpy as np

from .config import *
from .geometry import box_region, inset_region

def edge_map_lab(rgb: np.ndarray) -> np.ndarray:
    """Build a hue-independent contour map from Lab luminance and chroma."""
    lab = cv2.cvtColor(rgb, cv2.COLOR_RGB2LAB)
    return (
        (cv2.Canny(lab[:, :, 0], 40, 120) > 0)
        | (cv2.Canny(lab[:, :, 1], 18, 55) > 0)
        | (cv2.Canny(lab[:, :, 2], 18, 55) > 0)
    )

def _safe_distance_map(edge_map: np.ndarray) -> np.ndarray:
    return cv2.distanceTransform((~edge_map).astype(np.uint8), cv2.DIST_L2, cv2.DIST_MASK_PRECISE)

def sprite_contour_metrics(
    original_rgb: np.ndarray,
    final_rgb: np.ndarray,
    original_alpha: np.ndarray,
    final_alpha: np.ndarray,
    candidate_nontext_region: np.ndarray,
    available_region: np.ndarray,
    diagnostics: dict[str, float] | None = None,
) -> tuple[float, float]:
    """Measure contour displacement and optionally expose diagnostics."""

    def record(**values: float) -> None:
        if diagnostics is not None:
            diagnostics.update({
                key: float(value)
                for key, value in values.items()
            })

    diagnostic_keys = {
        "diagnostic_contour_source_point_count": 0.0,
        "diagnostic_contour_final_point_count": 0.0,
        "diagnostic_contour_available_source_edge_count": 0.0,
        "diagnostic_contour_available_final_edge_count": 0.0,
        "diagnostic_contour_source_to_final_ratio": 0.0,
        "diagnostic_contour_final_to_source_ratio": 0.0,
        "diagnostic_contour_source_to_final_capped_px": 0.0,
        "diagnostic_contour_final_to_source_capped_px": 0.0,
        "diagnostic_contour_orientation_matched_count": 0.0,
        "diagnostic_contour_match_radius_px": float(CONTOUR_MATCH_RADIUS_PX),
    }

    if not np.any(candidate_nontext_region):
        record(**diagnostic_keys)
        return 0.0, 0.0

    source_edges = (
        edge_map_lab(original_rgb)
        & (original_alpha > 16)
        & available_region
    )
    final_edges = (
        edge_map_lab(final_rgb)
        & (final_alpha > 16)
        & available_region
    )

    source_points = source_edges & candidate_nontext_region
    final_points = final_edges & candidate_nontext_region

    diagnostic_keys.update({
        "diagnostic_contour_source_point_count":
            float(np.count_nonzero(source_points)),
        "diagnostic_contour_final_point_count":
            float(np.count_nonzero(final_points)),
        "diagnostic_contour_available_source_edge_count":
            float(np.count_nonzero(source_edges)),
        "diagnostic_contour_available_final_edge_count":
            float(np.count_nonzero(final_edges)),
    })

    if not np.any(source_points) and not np.any(final_points):
        record(**diagnostic_keys)
        return 0.0, 0.0

    final_distance = _safe_distance_map(final_edges)
    source_distance = _safe_distance_map(source_edges)
    radius = float(CONTOUR_MATCH_RADIUS_PX)

    source_to_final_px = (
        float(np.mean(np.minimum(final_distance[source_points], radius)))
        if np.any(source_points) else 0.0
    )
    final_to_source_px = (
        float(np.mean(np.minimum(source_distance[final_points], radius)))
        if np.any(final_points) else 0.0
    )

    source_to_final = source_to_final_px / radius
    final_to_source = final_to_source_px / radius

    displacement = float(np.clip(
        0.60 * source_to_final + 0.40 * final_to_source,
        0.0, 1.0,
    ))

    src_gx, src_gy, src_mag = gradient_features(original_rgb)
    fin_gx, fin_gy, fin_mag = gradient_features(final_rgb)

    matched = (
        source_points
        & final_points
        & (src_mag > 50.0)
        & (fin_mag > 50.0)
    )

    if np.any(matched):
        denominator = src_mag[matched] * fin_mag[matched]
        dot = (
            src_gx[matched] * fin_gx[matched]
            + src_gy[matched] * fin_gy[matched]
        )
        orientation_loss = float(np.mean(
            1.0 - np.clip(
                np.abs(dot) / np.maximum(denominator, 1e-6),
                0.0, 1.0,
            )
        ))
    else:
        orientation_loss = 0.0

    diagnostic_keys.update({
        "diagnostic_contour_source_to_final_ratio": source_to_final,
        "diagnostic_contour_final_to_source_ratio": final_to_source,
        "diagnostic_contour_source_to_final_capped_px": source_to_final_px,
        "diagnostic_contour_final_to_source_capped_px": final_to_source_px,
        "diagnostic_contour_orientation_matched_count":
            float(np.count_nonzero(matched)),
    })
    record(**diagnostic_keys)

    return displacement, float(np.clip(orientation_loss, 0.0, 1.0))


def ink_strength_map(rgb: np.ndarray) -> np.ndarray:
    """Return hue-independent local contrast strength in [0, 1]."""
    lab_u8 = cv2.cvtColor(rgb, cv2.COLOR_RGB2LAB)
    lab = lab_u8.astype(np.float32)
    min_dim = min(lab.shape[:2])
    k = min(9, min_dim if min_dim % 2 == 1 else min_dim - 1)
    if k >= 3:
        local = cv2.medianBlur(lab_u8, k).astype(np.float32)
        luminance_delta = np.abs(lab[:, :, 0] - local[:, :, 0])
        da = lab[:, :, 1] - local[:, :, 1]
        db = lab[:, :, 2] - local[:, :, 2]
        chroma_delta = np.sqrt(da * da + db * db)
    else:
        luminance_delta = np.zeros(lab.shape[:2], dtype=np.float32)
        chroma_delta = np.zeros(lab.shape[:2], dtype=np.float32)

    luminance_strength = luminance_delta / 30.0
    chroma_strength = chroma_delta / 24.0
    return np.clip(np.maximum(luminance_strength, chroma_strength), 0.0, 1.0)

def make_contrast_mask(
    rgb: np.ndarray,
    alpha: np.ndarray,
    boxes: list[dict[str, Any]],
    threshold: float = 0.38,
    padding_px: int = CONTRAST_MASK_PADDING_PX,
) -> np.ndarray:
    """Build the experimental contrast mask inside inset OCR boxes.

    The thresholding and 3x3 morphological close match
    test_contrast_mask_on_images.py. Pixels outside the OCR-box union or
    effectively transparent source pixels are excluded from the mask.
    """
    if not 0.0 <= float(threshold) <= 1.0:
        raise ValueError(f"Contrast threshold must be in [0, 1], got {threshold!r}")
    if isinstance(padding_px, bool) or int(padding_px) != padding_px or padding_px < 0:
        raise ValueError(f"Contrast padding must be a non-negative integer, got {padding_px!r}")
    padding_px = int(padding_px)

    height, width = rgb.shape[:2]
    if alpha.shape != (height, width):
        raise ValueError(
            f"Alpha shape {alpha.shape!r} does not match RGB shape {(height, width)!r}"
        )

    detail = ink_strength_map(rgb)
    close_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
    threshold_binary = cv2.morphologyEx(
        (detail >= float(threshold)).astype(np.uint8),
        cv2.MORPH_CLOSE,
        close_kernel,
    ) > 0

    # Seed pixels are selected only inside the existing inset OCR ROIs.
    # The padded result may then grow back into the full OCR boxes, but never
    # outside them. This recovers glyph edges excluded by the current inset.
    roi_union = np.zeros((height, width), dtype=bool)
    box_union = np.zeros((height, width), dtype=bool)
    for box in boxes:
        if box.get("poly") is not None:
            # Polygon anchor: the ROI is the polygon eroded by the same asymmetric
            # inset (1 px horizontal, 2 px vertical); the hard limit is the polygon.
            region = box_region(box, width, height)
            if region is None:
                continue
            px1, py1, px2, py2, crop = region
            box_union[py1:py2 + 1, px1:px2 + 1] |= crop
            roi_union[py1:py2 + 1, px1:px2 + 1] |= inset_region(crop, 1, 2)
            continue
        try:
            x1 = max(0, min(width - 1, math.floor(float(box["x1"]))))
            y1 = max(0, min(height - 1, math.floor(float(box["y1"]))))
            x2 = max(0, min(width - 1, math.ceil(float(box["x2"]))))
            y2 = max(0, min(height - 1, math.ceil(float(box["y2"]))))
        except (KeyError, TypeError, ValueError, OverflowError):
            continue
        if x2 < x1 or y2 < y1:
            continue

        # Hard limit for the padded mask: never cross the OCR box boundary.
        box_union[y1:y2 + 1, x1:x2 + 1] = True

        # Same asymmetric inset used by the visual hard-image test.
        ix1, ix2 = min(x1 + 1, x2), max(x1, x2 - 1)
        iy1, iy2 = min(y1 + 2, y2), max(y1, y2 - 2)
        if ix2 < ix1 or iy2 < iy1:
            ix1, iy1, ix2, iy2 = x1, y1, x2, y2
        roi_union[iy1:iy2 + 1, ix1:ix2 + 1] = True

    visible = np.asarray(alpha) > ALPHA_VISIBILITY_THRESHOLD

    # Only in-ROI contrast pixels seed the mask. Padding expands them by N
    # pixels to cover thin antialiasing/stroke fringes missed by T38. The final
    # intersection with box_union prevents mask growth outside OCR boxes.
    padded_mask = threshold_binary & roi_union
    if padding_px:
        size = padding_px * 2 + 1
        padding_kernel = cv2.getStructuringElement(
            cv2.MORPH_ELLIPSE, (size, size)
        )
        padded_mask = cv2.dilate(
            padded_mask.astype(np.uint8), padding_kernel, iterations=1
        ) > 0

    return padded_mask & box_union & visible

def make_smart_ink_mask(
    rgb: np.ndarray,
    boxes: list[dict[str, Any]],
    inset_px: int = SMART_INK_INSET_PX,
    contrast_threshold: float = SMART_INK_CONTRAST_THRESHOLD,
    dilation_radius: int = SMART_INK_DILATION_RADIUS,
) -> np.ndarray:
    """Mask high-contrast text strokes inside OCR boxes while preserving borders and background."""
    h, w = rgb.shape[:2]
    mask = np.zeros((h, w), dtype=np.uint8)
    contrast = ink_strength_map(rgb)

    close_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
    dilate_kernel = cv2.getStructuringElement(
        cv2.MORPH_ELLIPSE, (dilation_radius * 2 + 1, dilation_radius * 2 + 1)
    )

    for b in boxes:
        if b.get("poly") is not None:
            # Polygon anchor: same logic inside the polygon eroded by inset_px.
            region = box_region(b, w, h)
            if region is None:
                continue
            px1, py1, px2, py2, crop = region
            roi = inset_region(crop, inset_px, inset_px)
            poly_contrast = contrast[py1:py2 + 1, px1:px2 + 1]
            poly_text = ((poly_contrast >= contrast_threshold) & roi).astype(np.uint8) * 255
            if np.any(poly_text):
                poly_closed = cv2.morphologyEx(poly_text, cv2.MORPH_CLOSE, close_kernel)
                poly_result = (cv2.dilate(poly_closed, dilate_kernel, iterations=1) > 0) & roi
            else:
                poly_result = roi
            mask[py1:py2 + 1, px1:px2 + 1][poly_result] = 255
            continue
        try:
            x1 = max(0, min(w - 1, int(math.floor(float(b["x1"])))))
            y1 = max(0, min(h - 1, int(math.floor(float(b["y1"])))))
            x2 = max(0, min(w - 1, int(math.ceil(float(b["x2"])))))
            y2 = max(0, min(h - 1, int(math.ceil(float(b["y2"])))))
        except (KeyError, TypeError, ValueError):
            continue
        if x2 <= x1 or y2 <= y1:
            continue

        ix1 = min(x1 + inset_px, x2)
        iy1 = min(y1 + inset_px, y2)
        ix2 = max(x2 - inset_px, x1)
        iy2 = max(y2 - inset_px, y1)

        if ix2 <= ix1 or iy2 <= iy1:
            ix1, iy1, ix2, iy2 = x1, y1, x2, y2

        box_contrast = contrast[iy1:iy2, ix1:ix2]
        text_pixels = (box_contrast >= contrast_threshold).astype(np.uint8) * 255
        if np.any(text_pixels):
            text_closed = cv2.morphologyEx(text_pixels, cv2.MORPH_CLOSE, close_kernel)
            text_dilated = cv2.dilate(text_closed, dilate_kernel, iterations=1)
            mask[iy1:iy2, ix1:ix2] = text_dilated
        else:
            mask[iy1:iy2, ix1:ix2] = 255

    return mask > 0

def gradient_features(rgb: np.ndarray) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    gray = cv2.cvtColor(rgb, cv2.COLOR_RGB2GRAY).astype(np.float32)
    gx = cv2.Sobel(gray, cv2.CV_32F, 1, 0, ksize=3)
    gy = cv2.Sobel(gray, cv2.CV_32F, 0, 1, ksize=3)
    mag = cv2.magnitude(gx, gy)
    return gx, gy, mag

def boundary_artifact_metrics(
    original_rgb: np.ndarray,
    final_rgb: np.ndarray,
    mask: np.ndarray,
    scoring_domain: np.ndarray,
    ignore_region: np.ndarray,
) -> tuple[float, float]:
    source_lab = cv2.cvtColor(original_rgb, cv2.COLOR_RGB2LAB).astype(np.float32)
    final_lab = cv2.cvtColor(final_rgb, cv2.COLOR_RGB2LAB).astype(np.float32)
    src_gx, src_gy, src_mag = gradient_features(original_rgb)
    fin_gx, fin_gy, fin_mag = gradient_features(final_rgb)

    color_penalties: list[np.ndarray] = []
    geometry_penalties: list[np.ndarray] = []
    pairs = [
        ((slice(None), slice(0, -1)), (slice(None), slice(1, None))),
        ((slice(0, -1), slice(None)), (slice(1, None), slice(None))),
    ]

    def orientation_gap(gx_a: np.ndarray, gy_a: np.ndarray,
                        gx_b: np.ndarray, gy_b: np.ndarray) -> np.ndarray:
        ma = np.sqrt(gx_a * gx_a + gy_a * gy_a)
        mb = np.sqrt(gx_b * gx_b + gy_b * gy_b)
        denom = ma * mb
        dot = gx_a * gx_b + gy_a * gy_b
        out = np.zeros_like(denom, dtype=np.float32)
        valid = denom > 25.0
        out[valid] = 1.0 - np.clip(np.abs(dot[valid]) / denom[valid], 0.0, 1.0)
        return out

    for sl_a, sl_b in pairs:
        ma, mb = mask[sl_a], mask[sl_b]
        choose_a = ma & ~mb & scoring_domain[sl_a] & ~ignore_region[sl_a]
        choose_b = mb & ~ma & scoring_domain[sl_b] & ~ignore_region[sl_b]
        if not np.any(choose_a) and not np.any(choose_b):
            continue

        src_la, src_lb = source_lab[sl_a], source_lab[sl_b]
        fin_la, fin_lb = final_lab[sl_a], final_lab[sl_b]
        src_colour_jump = np.linalg.norm(src_la - src_lb, axis=2) / 100.0
        fin_colour_jump = np.linalg.norm(fin_la - fin_lb, axis=2) / 100.0
        colour_increase = np.clip(fin_colour_jump - src_colour_jump, 0.0, 1.0)

        src_mag_a, src_mag_b = src_mag[sl_a], src_mag[sl_b]
        fin_mag_a, fin_mag_b = fin_mag[sl_a], fin_mag[sl_b]
        src_mag_step = np.abs(src_mag_a - src_mag_b) / 1020.0
        fin_mag_step = np.abs(fin_mag_a - fin_mag_b) / 1020.0
        step_increase = np.clip(fin_mag_step - src_mag_step, 0.0, 1.0)

        src_gap = orientation_gap(src_gx[sl_a], src_gy[sl_a], src_gx[sl_b], src_gy[sl_b])
        fin_gap = orientation_gap(fin_gx[sl_a], fin_gy[sl_a], fin_gx[sl_b], fin_gy[sl_b])
        orientation_increase = np.clip(fin_gap - src_gap, 0.0, 1.0)
        geometry_increase = 0.65 * step_increase + 0.35 * orientation_increase

        for choose in (choose_a, choose_b):
            if np.any(choose):
                color_penalties.append(colour_increase[choose])
                geometry_penalties.append(geometry_increase[choose])

    colour_score = float(np.mean(np.concatenate(color_penalties))) if color_penalties else 0.0
    geometry_score = float(np.mean(np.concatenate(geometry_penalties))) if geometry_penalties else 0.0
    return colour_score, geometry_score

def _retained_detail_ratio(
    source_detail: np.ndarray,
    final_detail: np.ndarray,
    region: np.ndarray,
    source_visible: np.ndarray,
    final_visible: np.ndarray,
) -> float:
    src = source_detail * region * source_visible
    fin = final_detail * region * final_visible
    source_energy = float(np.sum(src))
    if source_energy <= 1e-6:
        return 0.0
    same_location = float(np.sum(np.minimum(src, fin))) / source_energy
    detail_density = float(np.sum(fin)) / source_energy
    return float(0.90 * np.clip(same_location, 0.0, 1.0)
                 + 0.10 * np.clip(detail_density, 0.0, 1.0))

def residual_blob_contrast_ratio(
    final_rgb: np.ndarray,
    final_alpha: np.ndarray,
    text_target_region: np.ndarray,
    local_context_region: np.ndarray,
) -> float:
    """Detect low-/mid-frequency residue AND solid dark/bright discolored blocks."""
    visible = np.asarray(final_alpha) > 16
    target = np.asarray(text_target_region, dtype=bool) & visible
    context = np.asarray(local_context_region, dtype=bool) & visible
    if int(np.count_nonzero(target)) < 5:
        return 0.0

    lab = cv2.cvtColor(final_rgb, cv2.COLOR_RGB2LAB).astype(np.float32)
    lum = lab[:, :, 0]
    ca = lab[:, :, 1]
    cb = lab[:, :, 2]

    lum_sigma3 = cv2.GaussianBlur(lum, (0, 0), sigmaX=3.0, sigmaY=3.0)
    lum_sigma12 = cv2.GaussianBlur(lum, (0, 0), sigmaX=12.0, sigmaY=12.0)
    local_luma = np.abs(lum - lum_sigma12) / max(RESIDUAL_BLOB_LUMA_SCALE, 1e-6)
    medium_luma = np.abs(lum_sigma3 - lum_sigma12) / max(RESIDUAL_BLOB_LUMA_SCALE, 1e-6)

    a_sigma3 = cv2.GaussianBlur(ca, (0, 0), sigmaX=3.0, sigmaY=3.0)
    b_sigma3 = cv2.GaussianBlur(cb, (0, 0), sigmaX=3.0, sigmaY=3.0)
    a_sigma12 = cv2.GaussianBlur(ca, (0, 0), sigmaX=12.0, sigmaY=12.0)
    b_sigma12 = cv2.GaussianBlur(cb, (0, 0), sigmaX=12.0, sigmaY=12.0)
    chroma = np.sqrt((a_sigma3 - a_sigma12) ** 2 + (b_sigma3 - b_sigma12) ** 2)
    chroma = chroma / max(RESIDUAL_BLOB_CHROMA_SCALE, 1e-6)

    response = (
        0.40 * np.clip(local_luma, 0.0, 1.0)
        + 0.35 * np.clip(medium_luma, 0.0, 1.0)
        + 0.25 * np.clip(chroma, 0.0, 1.0)
    )
    target_values = response[target]
    target_signal = 0.65 * float(np.mean(target_values)) + 0.35 * float(np.percentile(target_values, 75))

    radius = max(1, int(RESIDUAL_BLOB_RING_RADIUS_PX))
    kernel_size = 2 * radius + 1
    kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (kernel_size, kernel_size))
    dilated_target = cv2.dilate(target.astype(np.uint8), kernel) > 0
    ring = dilated_target & ~target & context
    if np.any(ring):
        ring_values = response[ring]
        context_signal = 0.65 * float(np.mean(ring_values)) + 0.35 * float(np.percentile(ring_values, 75))

        # DC-Unterschied fängt flächige Verfärbungen / pechschwarze Balken ab:
        target_lum_mean = float(np.mean(lum[target]))
        ring_lum_mean = float(np.mean(lum[ring]))
        lum_dc_shift = abs(target_lum_mean - ring_lum_mean) / max(RESIDUAL_BLOB_LUMA_SCALE, 1e-6)

        target_ca_mean = float(np.mean(ca[target]))
        target_cb_mean = float(np.mean(cb[target]))
        ring_ca_mean = float(np.mean(ca[ring]))
        ring_cb_mean = float(np.mean(cb[ring]))
        chroma_dc_shift = math.sqrt((target_ca_mean - ring_ca_mean) ** 2 + (target_cb_mean - ring_cb_mean) ** 2) / max(RESIDUAL_BLOB_CHROMA_SCALE, 1e-6)

        dc_smudge_penalty = 0.70 * np.clip(lum_dc_shift, 0.0, 1.0) + 0.30 * np.clip(chroma_dc_shift, 0.0, 1.0)
    else:
        context_signal = 0.0
        dc_smudge_penalty = 0.0

    ac_excess = max(0.0, target_signal - context_signal)
    ac_blob = float(np.clip(ac_excess / max(RESIDUAL_BLOB_FULL_SCALE, 1e-6), 0.0, 1.0))
    return max(ac_blob, dc_smudge_penalty)

def residual_micro_component_metrics(
    source_detail: np.ndarray,
    final_detail: np.ndarray,
    text_region: np.ndarray,
    source_visible: np.ndarray,
    final_visible: np.ndarray,
    threshold: float = OUTLINE_LEAK_DETAIL_THRESHOLD,
    max_component_area: int = RESIDUAL_MICRO_COMPONENT_MAX_AREA,
) -> dict[str, float]:
    """Measure tiny high-contrast details retained at source-text locations.

    Aggregate text-detail metrics can dilute isolated small remnants. This
    metric counts connected components that are high-detail in both source
    and candidate, inside the OCR-linked text corridor. Components larger
    than max_component_area remain covered by the existing aggregate metrics.
    """
    target = (
        np.asarray(text_region, dtype=bool)
        & np.asarray(source_visible, dtype=bool)
        & np.asarray(final_visible, dtype=bool)
    )
    retained_components = (
        target
        & (np.asarray(source_detail) >= float(threshold))
        & (np.asarray(final_detail) >= float(threshold))
    )

    if not np.any(retained_components):
        return {
            "residual_micro_component_area": 0.0,
            "residual_micro_component_count": 0.0,
            "residual_micro_component_peak_area": 0.0,
            "residual_text_component_max_area": 0.0,
            "residual_text_large_component_area": 0.0,
            "residual_text_large_component_count": 0.0,
        }

    component_count, _labels, stats, _centroids = cv2.connectedComponentsWithStats(
        retained_components.astype(np.uint8),
        connectivity=8,
    )
    if component_count <= 1:
        areas = np.empty((0,), dtype=np.int32)
    else:
        areas = stats[1:, cv2.CC_STAT_AREA]

    areas = areas[areas > 0]
    area_limit = max(1, int(max_component_area))
    small_areas = areas[areas <= area_limit]
    large_areas = areas[areas > area_limit]

    return {
        "residual_micro_component_area": float(np.sum(small_areas)),
        "residual_micro_component_count": float(small_areas.size),
        "residual_micro_component_peak_area": (
            float(np.max(small_areas)) if small_areas.size else 0.0
        ),
        "residual_text_component_max_area": (
            float(np.max(areas)) if areas.size else 0.0
        ),
        "residual_text_large_component_area": float(np.sum(large_areas)),
        "residual_text_large_component_count": float(large_areas.size),
    }


def estimate_ocr_linked_text_corridor(
    source_detail: np.ndarray,
    box_mask: np.ndarray,
    near_ring: np.ndarray,
    yolo_reference_mask: np.ndarray,
    threshold: float = INK_STRENGTH_THRESHOLD,
    extra_padding: int = 2,
    source_visible: np.ndarray | None = None,
    diagnostics: dict[str, float] | None = None,
) -> np.ndarray:
    """Find text-linked detail, with a narrow fallback for OCR boxes lacking linked ink.

    Normal path: use high-contrast connected components linked to the YOLO mask.
    Fallback path: if an individual OCR box has no source-detail energy in that
    corridor, include only thresholded detail components inside that box plus a
    one-pixel edge margin. Do not fall back to the entire OCR box: its other
    pixels may belong to sprite structure that must remain protected.
    """
    visible_mask = (
        np.ones(box_mask.shape, dtype=bool)
        if source_visible is None
        else np.asarray(source_visible, dtype=bool)
    )
    if visible_mask.shape != box_mask.shape:
        raise ValueError("source_visible and box_mask must have identical shapes")

    detail_binary = (source_detail >= threshold).astype(np.uint8)
    close_kernel = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))
    detail_binary = cv2.morphologyEx(detail_binary, cv2.MORPH_CLOSE, close_kernel)
    component_count, labels = cv2.connectedComponents(detail_binary, connectivity=8)

    allowed_region = np.asarray(box_mask, dtype=bool) | np.asarray(near_ring, dtype=bool)
    linked = np.zeros(box_mask.shape, dtype=bool)

    if component_count > 1:
        link_radius = max(1, min(extra_padding, 3))
        link_size = 2 * link_radius + 1
        link_kernel = cv2.getStructuringElement(
            cv2.MORPH_ELLIPSE, (link_size, link_size)
        )
        linked_yolo_core = cv2.dilate(
            yolo_reference_mask.astype(np.uint8), link_kernel
        ) > 0
        seed = (detail_binary > 0) & box_mask & linked_yolo_core
        component_labels = np.unique(labels[seed])
        component_labels = component_labels[component_labels != 0]

        if component_labels.size:
            linked = np.isin(labels, component_labels)
            linked &= allowed_region
            if extra_padding > 0:
                size = 2 * extra_padding + 1
                kernel = cv2.getStructuringElement(
                    cv2.MORPH_ELLIPSE, (size, size)
                )
                linked = cv2.dilate(linked.astype(np.uint8), kernel) > 0
                linked &= allowed_region

    # Recover only high-detail pixels inside an OCR box when the YOLO-linked
    # corridor contributes no measurable source-detail energy to that box.
    # The recovery is restricted to the actual detail components and a 1px
    # margin around them, never to the whole rectangular OCR anchor.
    anchor_count, anchor_labels = cv2.connectedComponents(
        np.asarray(box_mask, dtype=np.uint8), connectivity=8
    )
    fallback_mask = np.zeros(box_mask.shape, dtype=bool)
    fallback_anchor_count = 0
    fallback_core_pixels = 0
    padding_px = min(max(int(extra_padding), 0), 1)
    if padding_px:
        pad_kernel = cv2.getStructuringElement(
            cv2.MORPH_ELLIPSE, (2 * padding_px + 1, 2 * padding_px + 1)
        )

    for anchor_id in range(1, anchor_count):
        anchor_region = anchor_labels == anchor_id
        current_energy = float(
            np.sum(source_detail[linked & anchor_region & visible_mask])
        )
        if current_energy > 1e-6:
            continue

        fallback_core = (detail_binary > 0) & anchor_region & visible_mask
        core_count = int(np.count_nonzero(fallback_core))
        if core_count == 0:
            continue

        fallback_anchor_count += 1
        fallback_core_pixels += core_count

        if padding_px:
            local_allowed = cv2.dilate(
                anchor_region.astype(np.uint8), pad_kernel
            ) > 0
            recovered = cv2.dilate(
                fallback_core.astype(np.uint8), pad_kernel
            ) > 0
            recovered &= local_allowed & allowed_region
        else:
            recovered = fallback_core & allowed_region

        fallback_mask |= recovered

    added_pixels = fallback_mask & ~linked
    linked |= fallback_mask

    if diagnostics is not None:
        diagnostics.update({
            "text_corridor_fallback_anchor_count": float(fallback_anchor_count),
            "text_corridor_fallback_core_pixels": float(fallback_core_pixels),
            "text_corridor_fallback_added_pixels": float(
                np.count_nonzero(added_pixels)
            ),
            "text_corridor_fallback_added_detail_pixels": float(
                np.count_nonzero(
                    added_pixels & visible_mask & (source_detail >= threshold)
                )
            ),
        })

    return linked

def outline_leak_metrics(
    source_detail: np.ndarray,
    source_alpha: np.ndarray,
    body_box_mask: np.ndarray,
    candidate_mask: np.ndarray,
) -> dict[str, float]:
    visible = source_alpha > 16
    body_region = body_box_mask & visible
    leak_region = body_region & ~candidate_mask
    total_energy = float(np.sum(source_detail[body_region]))
    leak_energy = float(np.sum(source_detail[leak_region]))
    leak_ratio = float(np.clip(leak_energy / max(total_energy, 1e-6), 0.0, 1.0)) if total_energy > 1e-6 else 0.0

    high_contrast = source_detail >= OUTLINE_LEAK_DETAIL_THRESHOLD
    leak_pixels = int(np.count_nonzero(leak_region & high_contrast))
    visible_pixels = int(np.count_nonzero(body_region))
    leak_density = float(leak_pixels / max(visible_pixels, 1))
    absolute_component = float(np.clip(
        leak_density / max(OUTLINE_LEAK_ABSOLUTE_DENSITY_FULL_SCALE, 1e-6), 0.0, 1.0
    ))
    score = float(np.clip(0.70 * leak_ratio + 0.30 * absolute_component, 0.0, 1.0))
    return {
        "outline_leak_ratio": leak_ratio,
        "outline_leak_absolute_density": leak_density,
        "outline_leak_score": score,
        "outline_leak_high_contrast_pixels": float(leak_pixels),
    }

def _peak_residual_ratio(
    source_detail: np.ndarray,
    final_detail: np.ndarray,
    region: np.ndarray,
    source_visible: np.ndarray,
    final_visible: np.ndarray,
    threshold: float = 0.20,
    min_pixels: int = 8,
) -> float:
    """Erkennt konzentrierte weiße Schmierer und Schrift-Antialiasing-Reste.
    
    Selbst winzige Cluster aus 10-20 hellen Pixeln auf dunklem Grund ruinieren
    das Bild für das menschliche Auge. Diese Funktion isoliert die intensivsten Reste.
    """
    valid = region & source_visible & final_visible
    if not np.any(valid):
        return 0.0
    src = source_detail[valid]
    fin = final_detail[valid]
    surviving = np.minimum(src, fin)
    
    # Nur Pixel betrachten, an denen im Original tatsächlich Schriftkontrast vorlag
    high_contrast_surviving = surviving[src >= threshold]
    if high_contrast_surviving.size < min_pixels:
        return 0.0
        
    top_count = max(min_pixels, min(32, int(high_contrast_surviving.size * 0.15)))
    top_values = np.partition(high_contrast_surviving, -top_count)[-top_count:]
    peak_mean = float(np.mean(top_values))
    
    if peak_mean <= 0.10:
        return 0.0
    return float(np.clip((peak_mean - 0.10) / 0.30, 0.0, 1.0))


# Lokale Schutzschranke gegen Kandidaten, die einen ganzen
# getrennten Ankerbereich praktisch unverändert stehen lassen.
# Wird nur zur Zulässigkeitsprüfung verwendet, nicht als Strukturkosten.
MAX_ANCHOR_RETAINED_DETAIL_FOR_ELIGIBILITY = 0.50


def _peak_residual_diagnostics(
    source_detail: np.ndarray,
    final_detail: np.ndarray,
    region: np.ndarray,
    source_visible: np.ndarray,
    final_visible: np.ndarray,
    prefix: str,
    threshold: float = 0.20,
    min_pixels: int = 8,
) -> dict[str, float]:
    """Expose peak statistics without changing the production score."""
    valid = region & source_visible & final_visible

    if not np.any(valid):
        return {
            f"{prefix}_raw_mean": 0.0,
            f"{prefix}_score": 0.0,
            f"{prefix}_candidate_pixel_count": 0.0,
            f"{prefix}_top_count": 0.0,
        }

    src = source_detail[valid]
    fin = final_detail[valid]
    surviving = np.minimum(src, fin)

    high_contrast_surviving = surviving[src >= threshold]
    candidate_count = int(high_contrast_surviving.size)

    if candidate_count == 0:
        raw_mean = 0.0
        top_count = 0
        peak_score = 0.0
    elif candidate_count < min_pixels:
        # Zu wenige Pixel für den produktiven Peakscore.
        # Den Mittelwert dennoch diagnostisch ausgeben.
        raw_mean = float(np.mean(high_contrast_surviving))
        top_count = candidate_count
        peak_score = 0.0
    else:
        top_count = max(
            min_pixels,
            min(32, int(candidate_count * 0.15)),
        )
        top_values = np.partition(
            high_contrast_surviving,
            -top_count,
        )[-top_count:]
        raw_mean = float(np.mean(top_values))

        if raw_mean <= 0.10:
            peak_score = 0.0
        else:
            peak_score = float(np.clip(
                (raw_mean - 0.10) / 0.30,
                0.0,
                1.0,
            ))

    return {
        f"{prefix}_raw_mean": raw_mean,
        f"{prefix}_score": peak_score,
        f"{prefix}_candidate_pixel_count": float(candidate_count),
        f"{prefix}_top_count": float(top_count),
    }


def score_candidate(
    original_rgb: np.ndarray,
    original_alpha: np.ndarray,
    final_rgb: np.ndarray,
    final_alpha: np.ndarray,
    mask: np.ndarray,
    scoring_envelope: np.ndarray,
    box_mask: np.ndarray,
    body_box_mask: np.ndarray,
    yolo_reference_mask: np.ndarray,
    outline_leak_precomputed: dict[str, float] | None = None,
) -> dict[str, float]:
    distance_to_box = cv2.distanceTransform((~box_mask).astype(np.uint8), cv2.DIST_L2, cv2.DIST_MASK_PRECISE)
    box_expanded = distance_to_box <= 10.000001
    source_visible = original_alpha > 16
    final_visible = final_alpha > 16
    near_ring = box_expanded & ~box_mask

    source_detail = ink_strength_map(original_rgb)
    final_detail = ink_strength_map(final_rgb)

    # Lokale Restdetails getrennt untersuchen.
    # Die einzelnen Rechtecke in box_mask sind räumlich getrennt.
    # Der bisherige globale Mittelwert kann einen komplett
    # unveränderten Bereich durch 19 andere Bereiche verdünnen.
    anchor_count, anchor_labels = cv2.connectedComponents(
        np.asarray(box_mask, dtype=np.uint8),
        connectivity=8,
    )

    anchor_residuals: list[tuple[int, float]] = []

    for anchor_id in range(1, anchor_count):
        anchor_region = anchor_labels == anchor_id
        source_anchor_visible = anchor_region & source_visible

        if not np.any(source_anchor_visible):
            continue

        region_source_energy = float(
            np.sum(source_detail[source_anchor_visible])
        )

        # Bereiche ohne relevante ursprüngliche Detailenergie
        # sollen keine künstlichen Extremwerte erzeugen.
        if region_source_energy <= 1e-6:
            continue

        anchor_residual = _retained_detail_ratio(
            source_detail,
            final_detail,
            anchor_region,
            source_visible,
            final_visible,
        )

        anchor_residuals.append(
            (
                anchor_id,
                float(np.clip(anchor_residual, 0.0, 1.0)),
            )
        )

    if anchor_residuals:
        max_anchor_id, max_anchor_retention = max(
            anchor_residuals,
            key=lambda entry: entry[1],
        )
    else:
        max_anchor_id = 0
        max_anchor_retention = 0.0

    corridor_fallback_diagnostics: dict[str, float] = {}
    text_corridor = estimate_ocr_linked_text_corridor(
        source_detail, box_mask, near_ring, yolo_reference_mask,
        extra_padding=TEXT_CORRIDOR_DILATION_PX,
        source_visible=source_visible,
        diagnostics=corridor_fallback_diagnostics,
    )
    if not np.any(text_corridor):
        fallback_target = box_mask & (source_detail >= OUTLINE_LEAK_DETAIL_THRESHOLD) & source_visible
        if np.any(fallback_target):
            fallback_kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (7, 7))
            text_corridor = cv2.dilate(fallback_target.astype(np.uint8), fallback_kernel) > 0
            text_corridor &= box_expanded

    # Textbezogene lokale Restprüfung:
    # Anders als max_anchor_retained_detail_ratio berücksichtigt
    # dieser Wert ausschließlich den ermittelten Textkorridor.
    # Dadurch sollen erhaltene Haare und Sprite-Kanten nicht
    # automatisch als verbliebene Schrift gelten.
    # Bereits vorhandene Detailwerte pro Anker als Rückfalloption.
    # Sie werden nur verwendet, wenn im jeweiligen Anker kein
    # ausreichend großer Textkorridor ausgewertet werden kann.
    anchor_residual_lookup = {
        int(anchor_id): float(retention)
        for anchor_id, retention in anchor_residuals
    }

    text_anchor_residuals: list[tuple[int, float]] = []
    text_anchor_fallback_region_count = 0

    for anchor_id in range(1, anchor_count):
        anchor_region = anchor_labels == anchor_id
        text_region = anchor_region & text_corridor
        visible_text_region = text_region & source_visible

        visible_text_count = int(
            np.count_nonzero(visible_text_region)
        )
        source_text_energy = float(
            np.sum(source_detail[visible_text_region])
        )

        if (
            visible_text_count >= 5
            and source_text_energy > 1e-6
        ):
            # Normalfall: ausschließlich den ermittelten Textkorridor
            # zur Beurteilung der verbliebenen Details verwenden.
            text_anchor_residual = _retained_detail_ratio(
                source_detail,
                final_detail,
                text_region,
                source_visible,
                final_visible,
            )
        else:
            # Kein auswertbarer Textkorridor in diesem Anker:
            # auf den bereits berechneten allgemeinen Detailwert
            # genau dieses Ankers zurückgreifen.
            fallback_ratio = anchor_residual_lookup.get(anchor_id)

            if fallback_ratio is None:
                continue

            text_anchor_residual = fallback_ratio
            text_anchor_fallback_region_count += 1

        text_anchor_residuals.append(
            (
                anchor_id,
                float(np.clip(text_anchor_residual, 0.0, 1.0)),
            )
        )

    if text_anchor_residuals:
        max_text_anchor_id, max_text_anchor_retention = max(
            text_anchor_residuals,
            key=lambda entry: entry[1],
        )
    else:
        max_text_anchor_id = 0
        max_text_anchor_retention = 0.0

    # --- REGEL 1: PEAK-SCHMIERER ERKENNUNG IM KASTEN ---
    inside_energy = _retained_detail_ratio(source_detail, final_detail, box_mask, source_visible, final_visible)
    inside_peak = _peak_residual_ratio(source_detail, final_detail, box_mask, source_visible, final_visible)
    # Kombiniere Gesamtenergie mit dem Spitzenwert (Schmierer schlagen voll durch!)
    inside_residual = float(np.clip(0.55 * inside_energy + 0.45 * inside_peak, 0.0, 1.0))

    # DIAGNOSTIK: dieselben Kennzahlen zusätzlich nur im Textkorridor
    # innerhalb der Box berechnen. Diese Werte verändern die Auswahl
    # noch nicht; sie dienen dem Vergleich mit der bisherigen Boxwertung.
    corridor_inside_region = box_mask & text_corridor
    corridor_source_pixels = corridor_inside_region & source_visible
    corridor_inside_pixel_count = int(
        np.count_nonzero(corridor_source_pixels)
    )
    corridor_source_energy = float(
        np.sum(source_detail[corridor_source_pixels])
    )


    # DIAGNOSTIK: Stärke und Anzahl der Peak-Pixel getrennt messen.
    # Die produktiven inside_peak- und Textscore-Berechnungen bleiben
    # unverändert.
    peak_diagnostics: dict[str, float] = {}

    peak_diagnostics.update(_peak_residual_diagnostics(
        source_detail,
        final_detail,
        box_mask,
        source_visible,
        final_visible,
        prefix="diagnostic_box_peak",
    ))

    peak_diagnostics.update(_peak_residual_diagnostics(
        source_detail,
        final_detail,
        corridor_inside_region,
        source_visible,
        final_visible,
        prefix="diagnostic_text_corridor_peak",
    ))

    if (
        corridor_inside_pixel_count >= 5
        and corridor_source_energy > 1e-6
    ):
        corridor_inside_energy = _retained_detail_ratio(
            source_detail,
            final_detail,
            corridor_inside_region,
            source_visible,
            final_visible,
        )
        corridor_inside_peak = _peak_residual_ratio(
            source_detail,
            final_detail,
            corridor_inside_region,
            source_visible,
            final_visible,
        )
        corridor_inside_residual = float(np.clip(
            0.55 * corridor_inside_energy
            + 0.45 * corridor_inside_peak,
            0.0,
            1.0,
        ))
        corridor_inside_fallback_used = 0.0
    else:
        # Bei zu wenig auswertbarem Textkorridor auf die bisherige
        # Boxwertung zurückfallen, aber diesen Fall explizit markieren.
        corridor_inside_energy = inside_energy
        corridor_inside_peak = inside_peak
        corridor_inside_residual = inside_residual
        corridor_inside_fallback_used = 1.0

    micro_component_metrics = residual_micro_component_metrics(
        source_detail,
        final_detail,
        box_expanded & text_corridor,
        source_visible,
        final_visible,
    )

    halo_text_region = near_ring & text_corridor & ~box_mask
    if np.any(halo_text_region):
        halo_energy = _retained_detail_ratio(source_detail, final_detail, halo_text_region, source_visible, final_visible)
        halo_peak = _peak_residual_ratio(source_detail, final_detail, halo_text_region, source_visible, final_visible)
        halo_residual = float(np.clip(0.55 * halo_energy + 0.45 * halo_peak, 0.0, 1.0))
        residual_text_detail = float(np.clip(0.85 * inside_residual + 0.15 * halo_residual, 0.0, 1.0))
    else:
        halo_residual = 0.0
        residual_text_detail = float(np.clip(inside_residual, 0.0, 1.0))

    residual_blob = residual_blob_contrast_ratio(
        final_rgb, final_alpha, text_corridor, box_expanded & source_visible
    )
    visual_text_residual = float(np.clip(
        (1.0 - RESIDUAL_BLOB_VISUAL_WEIGHT) * residual_text_detail
        + RESIDUAL_BLOB_VISUAL_WEIGHT * residual_blob,
        0.0, 1.0,
    ))

    leak = (
        outline_leak_precomputed
        if outline_leak_precomputed is not None
        else outline_leak_metrics(source_detail, original_alpha, body_box_mask, mask)
    )
    base_text_quality = visual_text_residual
    text_quality_score = float(np.clip(
        (1.0 - OUTLINE_LEAK_TEXT_WEIGHT) * base_text_quality
        + OUTLINE_LEAK_TEXT_WEIGHT * leak["outline_leak_score"], 0.0, 1.0
    ))

    # Alternative Textbewertung für den Vergleich:
    # Nur der Inside-Anteil wird auf den Textkorridor eingeschränkt.
    # Halo, Blob-Metrik und Leak-Gewichtung bleiben gleich.
    if np.any(halo_text_region):
        corridor_residual_text_detail = float(np.clip(
            0.85 * corridor_inside_residual
            + 0.15 * halo_residual,
            0.0,
            1.0,
        ))
    else:
        corridor_residual_text_detail = corridor_inside_residual

    corridor_visual_text_residual = float(np.clip(
        (1.0 - RESIDUAL_BLOB_VISUAL_WEIGHT)
        * corridor_residual_text_detail
        + RESIDUAL_BLOB_VISUAL_WEIGHT * residual_blob,
        0.0,
        1.0,
    ))

    corridor_base_text_quality = corridor_visual_text_residual

    corridor_text_quality_score = float(np.clip(
        (1.0 - OUTLINE_LEAK_TEXT_WEIGHT) * corridor_base_text_quality
        + OUTLINE_LEAK_TEXT_WEIGHT * leak["outline_leak_score"],
        0.0,
        1.0,
    ))

    available_nontext_region = box_expanded & source_visible & ~text_corridor
    candidate_nontext_region = mask & source_visible & ~text_corridor

    contour_debug: dict[str, float] = {}
    candidate_contour_displacement, contour_orientation_loss = sprite_contour_metrics(
        original_rgb, final_rgb, original_alpha, final_alpha,
        candidate_nontext_region, available_nontext_region,
        diagnostics=contour_debug,
    )

    # Gemeinsame Konturwertung: Alle Kandidaten im selben räumlichen Bereich.
    # Die kandidatenabhängige Konturwertung bleibt als Diagnosewert erhalten.
    common_contour_region = (
        np.asarray(scoring_envelope, dtype=bool)
        & available_nontext_region
    )

    common_contour_debug: dict[str, float] = {}
    common_contour_displacement, common_contour_orientation_loss = (
        sprite_contour_metrics(
            original_rgb,
            final_rgb,
            original_alpha,
            final_alpha,
            common_contour_region,
            common_contour_region,
            diagnostics=common_contour_debug,
        )
    )

    common_contour_components: dict[str, float] = {
        "diagnostic_common_contour_displacement_ratio":
            common_contour_displacement,
        "diagnostic_common_contour_orientation_loss_ratio":
            common_contour_orientation_loss,
        **{
            key.replace(
                "diagnostic_contour_",
                "diagnostic_common_contour_",
                1,
            ): value
            for key, value in common_contour_debug.items()
        },
    }


    # Produktive Konturverschiebung auf gemeinsamer Vergleichsregion.
    # Die Orientierungskomponente bleibt unverändert.
    contour_displacement = common_contour_displacement

    _src_gx, _src_gy, src_mag = gradient_features(original_rgb)
    _fin_gx, _fin_gy, fin_mag = gradient_features(final_rgb)
    source_edge = np.clip(src_mag / 1020.0, 0.0, 1.0)
    final_edge = np.clip(fin_mag / 1020.0, 0.0, 1.0)
    source_texture = cv2.GaussianBlur(source_edge, (0, 0), sigmaX=2.0, sigmaY=2.0)
    final_texture = cv2.GaussianBlur(final_edge, (0, 0), sigmaX=2.0, sigmaY=2.0)
    texture_delta = np.abs(source_texture - final_texture)
    fixed_region = scoring_envelope & available_nontext_region
    texture_denominator = max(
        float(np.sum(source_texture[fixed_region])),
        0.01 * int(np.count_nonzero(fixed_region)), 1e-6
    )
    texture_distortion = float(np.clip(
        np.sum(texture_delta[candidate_nontext_region]) / texture_denominator, 0.0, 1.0
    ))

    # --- REGEL 3A: PEAK COLOR-SHIFT (FARBFLECKEN-ERKENNUNG z.B. h008_001) ---
    source_lab = cv2.cvtColor(original_rgb, cv2.COLOR_RGB2LAB).astype(np.float32)
    final_lab = cv2.cvtColor(final_rgb, cv2.COLOR_RGB2LAB).astype(np.float32)
    delta_e = np.linalg.norm(source_lab - final_lab, axis=2)
    colour_change = np.clip(delta_e / 100.0, 0.0, 1.0)
    fixed_pixel_denominator = max(int(np.count_nonzero(fixed_region)), 1)
    avg_colour_shift = float(np.clip(
        np.sum(colour_change[candidate_nontext_region]) / fixed_pixel_denominator, 0.0, 1.0
    ))
    
    if np.any(candidate_nontext_region):
        shifts = colour_change[candidate_nontext_region]
        bad_shifts = shifts[shifts >= 0.20]  # Lokale Farbsprünge ab Delta-E 20
        if bad_shifts.size >= 8:
            k = min(24, bad_shifts.size)
            peak_color_shift = float(np.mean(np.partition(bad_shifts, -k)[-k:]))
        else:
            peak_color_shift = 0.0
    else:
        peak_color_shift = 0.0
    sprite_colour_shift = float(np.clip(0.60 * avg_colour_shift + 0.40 * peak_color_shift, 0.0, 1.0))

    boundary_colour, boundary_geometry = boundary_artifact_metrics(
        original_rgb, final_rgb, mask, box_expanded & source_visible, text_corridor
    )

    # --- REGEL 3B: PFEIL- & UI-SCHUTZ AUSSERHALB DER BOX (z.B. d002_000) ---
    # Prüft, ob außerhalb der Box liegende Nicht-Text-Kanten von der Maske rasiert wurden
    external_masked = mask & ~box_mask & ~text_corridor & source_visible
    source_external_edges = edge_map_lab(original_rgb) & external_masked
    final_external_edges = edge_map_lab(final_rgb) & external_masked
    erased_external_edges = int(np.count_nonzero(source_external_edges & ~final_external_edges))
    external_edge_destruction_score = float(np.clip(erased_external_edges / 12.0, 0.0, 1.0))

    components: dict[str, float] = {
        "residual_text_detail_ratio": residual_text_detail,
        "residual_inside_peak": float(inside_peak),
        "residual_inside_energy": float(inside_energy),
        **peak_diagnostics,
        "residual_blob_contrast_ratio": residual_blob,
        "visual_text_residual_score": visual_text_residual,
        "text_quality_base_score": float(np.clip(base_text_quality, 0.0, 1.0)),
        "text_quality_score": text_quality_score,
        **leak,
        **micro_component_metrics,
        **corridor_fallback_diagnostics,
        **contour_debug,
        **common_contour_components,
        "diagnostic_candidate_contour_displacement_ratio":
            candidate_contour_displacement,
        "sprite_contour_displacement_ratio": contour_displacement,
        "sprite_contour_orientation_loss_ratio": contour_orientation_loss,
        "sprite_texture_distortion_ratio": texture_distortion,
        "sprite_color_shift_ratio": sprite_colour_shift,
        "peak_color_shift_ratio": peak_color_shift,
        "boundary_color_artifact_ratio": float(np.clip(boundary_colour, 0.0, 1.0)),
        "boundary_geometry_artifact_ratio": float(np.clip(boundary_geometry, 0.0, 1.0)),
        "external_edge_destruction_score": external_edge_destruction_score,
        "residual_inside_box_ratio": float(np.clip(inside_residual, 0.0, 1.0)),
        "residual_inside_text_corridor_energy": float(corridor_inside_energy),
        "residual_inside_text_corridor_peak": float(corridor_inside_peak),
        "residual_inside_text_corridor_ratio": float(corridor_inside_residual),
        "text_corridor_inside_pixel_count": float(corridor_inside_pixel_count),
        "text_corridor_inside_fallback_used": float(corridor_inside_fallback_used),
        "text_quality_score_corridor_test": float(corridor_text_quality_score),
        "residual_near_box_ratio": float(np.clip(halo_residual, 0.0, 1.0)),
        "max_anchor_retained_detail_ratio": float(max_anchor_retention),
        "max_anchor_retained_detail_region": float(max_anchor_id),
        "anchor_region_count": float(len(anchor_residuals)),
        "max_text_anchor_retained_detail_ratio": float(max_text_anchor_retention),
        "max_text_anchor_retained_detail_region": float(max_text_anchor_id),
        "text_anchor_region_count": float(len(text_anchor_residuals)),
        "text_anchor_fallback_region_count": float(
            text_anchor_fallback_region_count
        ),
    }
    structure_score = sum(STRUCTURE_WEIGHTS[key] * components[key] for key in STRUCTURE_WEIGHTS)
    components["structure_score"] = float(structure_score)
    components["score"] = float(structure_score)
    for key, weight in STRUCTURE_WEIGHTS.items():
        components[f"weighted_{key}"] = weight * components[key]
    components["weighted_outline_leak_score"] = OUTLINE_LEAK_TEXT_WEIGHT * components["outline_leak_score"]
    return components

def select_candidate(
    scored: list[tuple[float, int | str, np.ndarray, dict[str, float]]],
) -> tuple[tuple[float, int | str, np.ndarray, dict[str, float]], float, float]:
    """Wählt den besten Kandidaten mit fehlerresistenter Box-Only-Rescue."""
    if not scored:
        raise ValueError("No scored mask candidates")

    text_scores = [item[3]["text_quality_score"] for item in scored]
    best_text = min(text_scores)
    spread = max(text_scores) - best_text
    tolerance = float(np.clip(
        TEXT_SCORE_TOLERANCE_RANGE_FRACTION * spread,
        TEXT_SCORE_TOLERANCE_FLOOR,
        TEXT_SCORE_TOLERANCE_CEILING,
    ))
    ceiling = best_text + tolerance

    # Zusätzliche lokale Schranke:
    # Ein Kandidat mit einem stark verbliebenen Einzelbereich
    # darf nicht allein wegen eines guten Gesamtdurchschnitts gewinnen.
    anchor_ratios = [
        float(item[3].get(
            "max_text_anchor_retained_detail_ratio",
            item[3].get("max_anchor_retained_detail_ratio", 0.0),
        ))
        for item in scored
    ]

    text_quality_flags = [
        float(item[3]["text_quality_score"]) <= ceiling + TEXT_SCORE_BOUNDARY_SLACK + 1e-9
        for item in scored
    ]

    # Ein "sauberer" Kandidat zählt für den absoluten Grenzwert nur,
    # wenn er auch die globale Textqualitätsgrenze erfüllt.
    has_anchor_clean_candidate = any(
        text_ok
        and ratio <= MAX_ANCHOR_RETAINED_DETAIL_FOR_ELIGIBILITY + 1e-9
        for ratio, text_ok in zip(anchor_ratios, text_quality_flags)
    )

    if has_anchor_clean_candidate:
        anchor_eligibility_limit = (
            MAX_ANCHOR_RETAINED_DETAIL_FOR_ELIGIBILITY
        )
    else:
        # Wenn kein global textqualitativ zulässiger Kandidat den
        # absoluten Grenzwert erreicht, dient der beste lokale Wert
        # innerhalb der textqualitativ zulässigen Kandidaten als
        # Referenz. Dadurch wird ein Kandidat wie BOX_ONLY nicht
        # allein wegen eines geringfügig höheren Detailrests gesperrt.
        text_eligible_anchor_ratios = [
            ratio
            for ratio, text_ok in zip(anchor_ratios, text_quality_flags)
            if text_ok
        ]

        reference_ratios = (
            text_eligible_anchor_ratios
            if text_eligible_anchor_ratios
            else anchor_ratios
        )

        anchor_eligibility_limit = min(
            1.0,
            min(reference_ratios) + 0.02,
        )

    # Die gemeinsame Zulässigkeitsprüfung muss dieselbe lokale Metrik
    # benutzen wie die anschließende Prüfung jedes Kandidaten.
    joint_eligible_exists = any(
        text_ok
        and ratio <= anchor_eligibility_limit + 1e-9
        for ratio, text_ok in zip(anchor_ratios, text_quality_flags)
    )

    # Die Textqualitätsgrenze wird nur dann übergangen, wenn tatsächlich
    # kein Kandidat beide Bedingungen erfüllt.
    anchor_fallback_mode = not joint_eligible_exists

    box_item = next((item for item in scored if item[1] == "BOX_ONLY"), None)
    yolo_items = [item for item in scored if isinstance(item[1], int)]

    box_rescue = False
    rescue_advantage = 0.0
    rescue_yolo_leak = 0.0
    rescue_reason = 0.0
    rescue_inside_advantage = 0.0
    rescue_box_inside_residual = float("nan")
    rescue_best_yolo_inside_residual = float("nan")

    if BOX_ONLY_RESCUE_ENABLED and box_item is not None and yolo_items:
        best_yolo_by_text = min(yolo_items, key=lambda item: item[3]["text_quality_score"])
        # Für die Artefaktreferenz alle Alternativen berücksichtigen,
        # einschließlich HYBRID_D2, HYBRID_D6 und SMART_INK.
        # Die separate YOLO-Text-/Inside-Referenz bleibt unverändert.
        best_non_box_by_structure = min(
            (item for item in scored if item[1] != "BOX_ONLY"),
            key=lambda item: item[3]["structure_score"],
        )
        best_yolo_text_score = float(best_yolo_by_text[3]["text_quality_score"])
        box_text_score = float(box_item[3]["text_quality_score"])
        
        # 1. SCHRANKE: Wenn YOLO bereits absolut sauber ist (< 0.03), NIEMALS retten!
        yolo_already_clean = best_yolo_text_score <= 0.030

        # 2. SCHRANKE: Wenn Box-Only selbst Halluzinationen/Schmierer erzeugt, NIEMALS retten!
        # Strukturkosten entscheiden weiterhin über die Rangfolge,
        # sind aber keine eigenständige Artefaktprüfung.
        # Der Farbwechsel wird relativ zum besten YOLO-Textkandidaten
        # verglichen, damit ein allen Kandidaten gemeinsamer hoher Wert
        # BOX_ONLY nicht pauschal blockiert.
        box_peak_shift = float(
            box_item[3].get("peak_color_shift_ratio", 0.0)
        )
        # Peak-Farbverschiebung mit dem strukturell besten YOLO-
        # Kandidaten vergleichen. Der Text-Benchmark bleibt getrennt.
        comparator_peak_shift = float(
            best_non_box_by_structure[3].get(
                "peak_color_shift_ratio", box_peak_shift
            )
        )

        box_has_artifacts = (
            box_peak_shift > comparator_peak_shift + 0.15
            or box_item[3].get("residual_blob_contrast_ratio", 0.0) > 0.10
            or float(
                box_item[3].get(
                    "max_text_anchor_retained_detail_ratio",
                    box_item[3].get("max_anchor_retained_detail_ratio", 0.0),
                )
            ) > anchor_eligibility_limit + 1e-9
        )

        if not yolo_already_clean and not box_has_artifacts:
            rescue_advantage = max(0.0, best_yolo_text_score - box_text_score)
            
            best_yolo_by_inside = min(yolo_items, key=lambda item: item[3].get("residual_inside_box_ratio", 1.0))
            box_inside = float(box_item[3].get("residual_inside_box_ratio", 1.0))
            yolo_inside = float(best_yolo_by_inside[3].get("residual_inside_box_ratio", 1.0))
            rescue_inside_advantage = max(0.0, yolo_inside - box_inside)
            rescue_yolo_leak = float(best_yolo_by_text[3].get("outline_leak_score", 0.0))

            # Reale Schwellenwerte statt Rausch-Empfindlichkeit (0.02 statt 0.006)
            if rescue_advantage >= 0.020:
                box_rescue = True
                rescue_reason = 2.0
            elif rescue_advantage >= 0.010 and rescue_yolo_leak >= BOX_ONLY_RESCUE_MIN_YOLO_LEAK_SCORE:
                box_rescue = True
                rescue_reason = 1.0
            elif yolo_inside >= 0.12 and rescue_inside_advantage >= 0.04:
                box_rescue = True
                rescue_reason = 3.0
            elif (
                rescue_advantage >= 0.015
                and rescue_inside_advantage >= 0.025
            ):
                # Zusätzliche relative Regel:
                # BOX_ONLY muss gleichzeitig beim Textscore und beim
                # Inside-Residual merklich besser sein.
                box_rescue = True
                rescue_reason = 4.0

    for _score, candidate_id, _mask, metrics in scored:
        text_eligible = (
            metrics["text_quality_score"] <= ceiling + TEXT_SCORE_BOUNDARY_SLACK + 1e-9
        )

        anchor_eligible = (
            float(metrics.get(
                "max_text_anchor_retained_detail_ratio",
                metrics.get("max_anchor_retained_detail_ratio", 0.0),
            )) <= anchor_eligibility_limit + 1e-9
        )

        default_eligible = anchor_eligible and (
            text_eligible or anchor_fallback_mode
        )

        # Eine evidenzbasierte BOX_ONLY-Rescue darf die globale Textscore-Grenze
        # übergehen. Die lokale Anker-/Detail-Schranke bleibt weiterhin aktiv.
        if box_rescue:
            eligible = candidate_id == "BOX_ONLY" and anchor_eligible
        else:
            eligible = default_eligible

        metrics["anchor_detail_eligible"] = (
            1.0 if anchor_eligible else 0.0
        )
        metrics["anchor_detail_eligibility_limit"] = float(
            anchor_eligibility_limit
        )
        metrics["anchor_detail_fallback_mode"] = (
            1.0 if anchor_fallback_mode else 0.0
        )

        metrics["best_text_quality_score"] = float(best_text)
        metrics["text_quality_tolerance"] = tolerance
        metrics["text_quality_eligible"] = 1.0 if eligible else 0.0
        metrics["box_only_rescue_applied"] = 1.0 if box_rescue else 0.0
        metrics["box_only_rescue_final_text_advantage"] = rescue_advantage
        metrics["box_only_rescue_best_yolo_leak_score"] = rescue_yolo_leak
        metrics["box_only_rescue_inside_detail_advantage"] = rescue_inside_advantage
        metrics["box_only_rescue_box_inside_residual"] = rescue_box_inside_residual
        metrics["box_only_rescue_best_yolo_inside_residual"] = rescue_best_yolo_inside_residual
        metrics["box_only_rescue_reason_code"] = rescue_reason
        metrics["residual_spot_tiebreak_applied"] = 0.0
        metrics["residual_spot_tiebreak_structure_margin"] = 0.0
        metrics["residual_spot_tiebreak_area_reduction"] = 0.0
        metrics["score"] = metrics["structure_score"] if eligible else 2.0 + metrics["structure_score"]

    def tie_break(candidate_id: int | str) -> tuple[int, int]:
        if isinstance(candidate_id, int):
            return (0, candidate_id)
        if candidate_id == "SMART_INK":
            return (1, 0)
        return (2, 9999)

    winner = min(scored, key=lambda item: (
        item[3]["score"], item[3]["structure_score"], item[3]["text_quality_score"], tie_break(item[1])
    ))
    # Konservative Zweitentscheidung: Bei nahezu gleichem Struktur-Score
    # darf ein Kandidat mit deutlich weniger kleinen Textresten gewinnen.
    baseline_winner = winner
    baseline_structure = float(baseline_winner[3]["structure_score"])
    baseline_micro_area = float(
        baseline_winner[3].get("residual_micro_component_area", 0.0)
    )
    near_optimal = [
        item
        for item in scored
        if float(item[3].get("score", 2.0)) < 2.0
        and float(item[3]["structure_score"])
        <= baseline_structure + RESIDUAL_SPOT_STRUCTURE_TOLERANCE + 1e-9
    ]
    if near_optimal:
        # Zusätzlicher Sprite-Schutz: ein Kandidat mit deutlich mehr
        # Konturverlust darf den Basisgewinner nicht nur wegen weniger
        # kleiner Restkomponenten verdrängen.
        baseline_contour_displacement = float(
            baseline_winner[3].get("sprite_contour_displacement_ratio", 0.0)
        )
        max_allowed_contour_displacement = (
            baseline_contour_displacement
            + RESIDUAL_SPOT_MAX_CONTOUR_DISPLACEMENT_INCREASE
        )
        near_optimal = [
            item for item in near_optimal
            if float(item[3].get(
                "sprite_contour_displacement_ratio",
                baseline_contour_displacement,
            )) <= max_allowed_contour_displacement + 1e-9
        ]

    if near_optimal:
        cleanest_area = min(
            float(item[3].get("residual_micro_component_area", 0.0))
            for item in near_optimal
        )
        area_reduction = baseline_micro_area - cleanest_area
        if area_reduction >= RESIDUAL_SPOT_MIN_AREA_REDUCTION_PX:
            cleaner_candidates = [
                item
                for item in near_optimal
                if float(item[3].get("residual_micro_component_area", 0.0))
                == cleanest_area
            ]
            cleaner_winner = min(cleaner_candidates, key=lambda item: (
                item[3]["structure_score"],
                item[3]["text_quality_score"],
                tie_break(item[1]),
            ))
            if cleaner_winner[1] != baseline_winner[1]:
                cleaner_winner[3]["residual_spot_tiebreak_applied"] = 1.0
                cleaner_winner[3]["residual_spot_tiebreak_structure_margin"] = max(
                    0.0,
                    float(cleaner_winner[3]["structure_score"]) - baseline_structure,
                )
                cleaner_winner[3]["residual_spot_tiebreak_area_reduction"] = float(
                    area_reduction
                )
                winner = cleaner_winner


    return winner, float(best_text), tolerance

class ParsingTests(unittest.TestCase):

        self.assertTrue(mask[10, 15])

        self.assertTrue(mask[20, 40])  # the red rectangle fallback covers the notch

class PolygonMaskTests(unittest.TestCase):
    def test_polygon_excludes_notch_rectangle_does_not(self):
        poly_mask = make_box_only_mask(60, 30, [l_box()]) > 0
        rect_mask = make_box_only_mask(60, 30, [{"x1": 10, "y1": 5, "x2": 49, "y2": 24}]) > 0
        self.assertTrue(poly_mask[20, 15])      # lower-left arm
        self.assertFalse(poly_mask[20, 40])     # notch
        self.assertTrue(rect_mask[20, 40])
        self.assertTrue(np.all(rect_mask >= poly_mask))

    def test_read_anchor_csv_keeps_polygon(self):
        with tempfile.TemporaryDirectory() as tmp:
            path = Path(tmp) / "anchors.csv"
            with path.open("w", encoding="utf-8-sig", newline="") as f:
                w = csv.DictWriter(f, fieldnames=["image", "type", "x1", "y1", "x2", "y2", "polygon", "mask_polygon"])
                w.writeheader()
                w.writerow({"image": "a.png", "type": "body", "x1": 10, "y1": 5, "x2": 49, "y2": 24,
                            "polygon": L_ROW["polygon"], "mask_polygon": L_POLY})
                w.writerow({"image": "a.png", "type": "header", "x1": 0, "y1": 0, "x2": 5, "y2": 5,
                            "polygon": "0,0;5,0;5,5;0,5", "mask_polygon": ""})
            _fields, _rows, by_image = read_anchor_csv(path)
        body, header = by_image["a.png"]
        self.assertIsNotNone(body["poly"])
        self.assertIsNone(header["poly"])

    def test_contrast_and_smart_ink_stay_inside_polygon(self):
        rng = np.random.default_rng(3)
        rgb = rng.integers(0, 255, (30, 60, 3), dtype=np.uint8)
        alpha = np.full((30, 60), 255, dtype=np.uint8)
        poly_region = make_box_only_mask(60, 30, [l_box()]) > 0
        self.assertFalse((make_contrast_mask(rgb, alpha, [l_box()]) & ~poly_region).any())
        self.assertFalse((make_smart_ink_mask(rgb, [l_box()]) & ~poly_region).any())

    def test_coverage_uses_polygon_and_exclude_mask(self):
        h, w = 30, 60
        alpha = np.full((h, w), 255, dtype=np.uint8)
        detail = np.zeros((h, w), dtype=np.float32)
        detail[5:25, 10:50] = 0.8
        full = np.full((h, w), 255, dtype=np.uint8)
        self.assertEqual(overlap_with_box(full, l_box()), int((make_box_only_mask(w, h, [l_box()]) > 0).sum()))
        # A mask covering only the notch must not count as covering the polygon.
        notch = np.zeros((h, w), dtype=np.uint8)
        notch[16:25, 32:50] = 255
        self.assertEqual(body_box_coverage_metrics(notch, detail, alpha, l_box())["overlap_pixels"], 0)
        # Excluded pixels outside the polygon change nothing ...
        left_only = np.zeros((h, w), dtype=np.uint8)
        left_only[5:25, 10:30] = 255
        exclude = np.zeros((h, w), dtype=bool)
        exclude[16:25, 32:50] = True  # lies in the notch (outside the polygon): must change nothing
        base = body_box_coverage_metrics(left_only, detail, alpha, l_box())
        self.assertEqual(body_box_coverage_metrics(left_only, detail, alpha, l_box(), exclude_mask=exclude), base)
        # ... while excluded pixels inside the polygon are no longer required coverage.
        inside = np.zeros((h, w), dtype=bool)
        inside[5:15, 31:50] = True
        with_exclude = body_box_coverage_metrics(left_only, detail, alpha, l_box(), exclude_mask=inside)
        self.assertLess(with_exclude["visible_box_pixels"], base["visible_box_pixels"])
        self.assertGreater(with_exclude["detail_energy_coverage_ratio"], base["detail_energy_coverage_ratio"])


class ProtectedZoneTests(unittest.TestCase):
    def _csv(self, tmp: str) -> Path:
        path = Path(tmp) / "protected_zones.csv"
        with path.open("w", encoding="utf-8-sig", newline="") as f:
            w = csv.DictWriter(f, fieldnames=["image", "zone_id", "x1", "y1", "x2", "y2", "polygon", "text"])
            w.writeheader()
            w.writerow({"image": "a.png", "zone_id": "a#z1", "x1": 2, "y1": 3, "x2": 6, "y2": 5,
                        "polygon": "2,3;6,3;6,5;2,5", "text": "OK"})
            w.writerow({"image": "a.png", "zone_id": "bad", "x1": "x", "y1": 0, "x2": 1, "y2": 1, "polygon": "", "text": ""})
        return path

    def test_default_protected_csv_is_discovered_next_to_anchors(self):
        with tempfile.TemporaryDirectory() as tmp:
            anchors = Path(tmp) / "anchors.csv"
            anchors.touch()
            expected = Path(tmp) / "protected_zones.csv"
            self.assertIsNone(geometry.resolve_protected_zones_csv(anchors))
            expected.touch()
            self.assertEqual(geometry.resolve_protected_zones_csv(anchors), expected)

    def test_explicit_protected_csv_overrides_sibling_discovery(self):
        with tempfile.TemporaryDirectory() as tmp:
            anchors = Path(tmp) / "anchors.csv"
            explicit = Path(tmp) / "elsewhere" / "zones.csv"
            resolved = geometry.resolve_protected_zones_csv(anchors, explicit)
            self.assertEqual(resolved, explicit.resolve())

    def test_read_and_mask(self):
        with tempfile.TemporaryDirectory() as tmp:
            zones = geometry.read_protected_zones(self._csv(tmp))
        self.assertEqual(len(zones["a.png"]), 1)          # invalid row skipped
        mask = geometry.protected_mask(zones["a.png"], 20, 10)
        self.assertTrue(mask[3, 2] and mask[5, 6])         # inclusive corners
        self.assertEqual(int(mask.sum()), 5 * 3)
        self.assertGreater(int(geometry.protected_mask(zones["a.png"], 20, 10, margin_px=1).sum()), 15)

    def test_no_candidate_touches_protected_pixels(self):
        rng = np.random.default_rng(7)
        h, w = 30, 60
        rgb = rng.integers(0, 255, (h, w, 3), dtype=np.uint8)
        alpha = np.full((h, w), 255, dtype=np.uint8)
        zone = {"x1": 20.0, "y1": 8.0, "x2": 35.0, "y2": 20.0, "poly": None}
        yolo = {d: np.ones((h, w), dtype=bool) for d in (0, 2, 4, 6, 8, 10)}
        ms = build_image_mask_set(
            rgb=rgb, alpha=alpha, boxes=[l_box()], zones=[zone], yolo_masks=yolo,
            box_only_mask=make_box_only_mask(w, h, [l_box()]) > 0,
            contrast_thresholds=(0.38,), contrast_candidate_ids=["CONTRAST_T38"],
        )
        self.assertEqual(list(ms.candidates)[:6], [0, 2, 4, 6, 8, 10])
        self.assertEqual(list(ms.candidates)[6:], ["HYBRID_D2", "HYBRID_D6", "CONTRAST_T38", "SMART_INK", "BOX_ONLY"])
        self.assertTrue(ms.protected.any())
        for cid, mask in ms.candidates.items():
            self.assertFalse((mask & ms.protected).any(), cid)
        for ref in (ms.box_mask, ms.body_box_mask, ms.yolo_reference_mask, ms.scoring_envelope):
            self.assertFalse((ref & ms.protected).any())

    def test_without_zones_masks_equal_unprotected_masks(self):

The script reruns the existing YOLO segmentation model (inference only) so it can
inspect individual instance masks, not just the already-unioned mask images.
For each image it:
  * checks whether every red/body anchor box intersects at least one YOLO mask;
  * estimates the distance of each YOLO instance mask to the nearest OCR anchor;
  * trims each YOLO instance mask pixel-by-pixel to a distance band around OCR boxes;
  * saves a box-only baseline and visual overlays for side-by-side inspection.

It never modifies source images, anchors.csv, raw/, cleaned/, or existing tests.

def norm_name(value: str) -> str:
    return " ".join(value.casefold().replace("_", " ").replace("-", " ").split())


def requested_class(name: str) -> bool:
    normalized = norm_name(name)
    return normalized in {
        "text", "text region", "dialogue text", "printed text", "caption",
        "sfx", "sound effect", "sound effects", "onomatopoeia",
    }


def image_name_from(row: dict[str, str]) -> str:
    return Path((row.get("image") or "").strip()).name


def read_anchors(path: Path) -> tuple[dict[str, list[dict[str, Any]]], set[str]]:
    if not path.is_file():
        raise FileNotFoundError(f"anchors CSV not found: {path}")
    by_image: dict[str, list[dict[str, Any]]] = defaultdict(list)
    with path.open("r", encoding="utf-8-sig", newline="") as f:
        reader = csv.DictReader(f)
        required = {"image", "type", "x1", "y1", "x2", "y2"}
        missing = required - set(reader.fieldnames or [])
        if missing:
            raise ValueError("CSV missing columns: " + ", ".join(sorted(missing)))
        for row_number, row in enumerate(reader, start=2):
            name = image_name_from(row)
            if not name:
                continue
            try:
                x1, y1, x2, y2 = [float(row[k]) for k in ("x1", "y1", "x2", "y2")]
                if not all(math.isfinite(v) for v in (x1, y1, x2, y2)) or x2 <= x1 or y2 <= y1:
                    raise ValueError
            except (KeyError, TypeError, ValueError):
                print(f"WARN: invalid box ignored at CSV line {row_number}: {name}", file=sys.stderr)
                continue
            label = (row.get("type") or "").strip().casefold()
            by_image[name].append({
                "type": label, "x1": x1, "y1": y1, "x2": x2, "y2": y2,
                "anchor_id": (row.get("anchor_id") or "").strip(),
                "row": (row.get("row") or "").strip(),
                "col": (row.get("col") or "").strip(),
                "csv_line": row_number,
                "poly": anchor_polygon(row),
            })
    if not by_image:
        raise ValueError(f"No valid anchor boxes found in {path}")
    return by_image, set(by_image)


def discover_images(images_dir: Path, known_names: set[str]) -> list[Path]:
    if not images_dir.is_dir():
        raise FileNotFoundError(f"source images directory not found: {images_dir}")
    found: dict[str, list[Path]] = defaultdict(list)
    for p in images_dir.rglob("*"):
        if p.is_file() and p.suffix.lower() in IMAGE_EXTS and p.name in known_names:
            found[p.name].append(p)
    duplicates = {name: vals for name, vals in found.items() if len(vals) > 1}
    if duplicates:
        examples = "; ".join(f"{name}: {len(vals)} files" for name, vals in list(duplicates.items())[:8])
        raise ValueError("Duplicate source-image basenames; refusing to guess: " + examples)
    paths = [vals[0] for _, vals in found.items()]
    return sorted(paths, key=lambda p: (p.name.casefold(), str(p)))


def rect_bounds(box: dict[str, Any], w: int, h: int) -> tuple[int, int, int, int] | None:
    x1 = max(0, min(w - 1, math.floor(box["x1"])))
    y1 = max(0, min(h - 1, math.floor(box["y1"])))
    x2 = max(0, min(w - 1, math.ceil(box["x2"])))
    y2 = max(0, min(h - 1, math.ceil(box["y2"])))
    if x2 < x1 or y2 < y1:
        return None
    return x1, y1, x2, y2


def draw_box_mask(size: tuple[int, int], boxes: list[dict[str, Any]]) -> np.ndarray:
    """Union of all boxes (polygon where available, else rectangle) as uint8 0/255."""
    w, h = size
    return boxes_union_mask(boxes, w, h).astype(np.uint8) * 255


def dilate(mask: np.ndarray, radius: int) -> np.ndarray:
    if radius <= 0:
        return mask
    kernel = np.ones((radius * 2 + 1, radius * 2 + 1), dtype=np.uint8)
    return cv2.dilate(mask, kernel, iterations=1)


def polygon_mask(poly: Any, w: int, h: int, dilation: int) -> np.ndarray:
    mask = np.zeros((h, w), dtype=np.uint8)
    pts = np.asarray(poly, dtype=np.float32)
    if pts.ndim != 2 or pts.shape[0] < 3 or pts.shape[1] != 2:
        return mask
    pts = np.rint(pts).astype(np.int32)
    pts[:, 0] = np.clip(pts[:, 0], 0, w - 1)
    pts[:, 1] = np.clip(pts[:, 1], 0, h - 1)
    cv2.fillPoly(mask, [pts], 255)
    return dilate(mask, dilation)


def min_distance_to_boxes(instance_mask: np.ndarray, box_distance: np.ndarray) -> float:
    ys, xs = np.nonzero(instance_mask)
    if len(xs) == 0:
        return float("inf")
    return float(np.min(box_distance[ys, xs]))


def overlap_with_box(mask: np.ndarray, box: dict[str, Any]) -> int:
    h, w = mask.shape
    region = box_region(box, w, h)
    if region is None:
        return 0
    x1, y1, x2, y2, crop = region
    return int(np.count_nonzero((mask[y1:y2 + 1, x1:x2 + 1] > 0) & crop))


def body_box_coverage_metrics(
    candidate_mask: np.ndarray,
    source_detail: np.ndarray,
    source_alpha: np.ndarray,
    box: dict[str, Any],
    exclude_mask: np.ndarray | None = None,
) -> dict[str, Any]:
    """Measure meaningful YOLO coverage of a body OCR box, not just any overlap.

    The box is its polygon if it has one. Pixels in ``exclude_mask`` (protected zones)
    are ignored: they can never be masked, so they must not count as missing coverage.

    Ratios are calculated over visible source pixels in the box. Detail-energy
    coverage measures how much original local contrast is actually covered;
    high-contrast coverage adds a check for missed outlines/strokes. Boxes with
    no measurable contrast cannot fail the contrast-ratio test, but still need a
    non-trivial absolute mask overlap.
    """
    h, w = candidate_mask.shape
    region = box_region(box, w, h)
    if region is None:
        return {
            "raw_overlap_nonzero": False, "overlap_pixels": 0,
            "visible_box_pixels": 0, "minimum_required_overlap_pixels": BODY_BOX_MIN_OVERLAP_PIXELS,
            "box_overlap_fraction": 0.0, "detail_energy_coverage_ratio": 0.0,
            "high_contrast_coverage_ratio": float("nan"), "high_contrast_pixels": 0,
            "covered_high_contrast_pixels": 0, "combined_detail_coverage_score": 0.0,
            "meaningfully_covered": False,
        }
    x1, y1, x2, y2, region_crop = region
    region_alpha = source_alpha[y1:y2 + 1, x1:x2 + 1]
    visible = (region_alpha > ALPHA_VISIBILITY_THRESHOLD) & region_crop
    if exclude_mask is not None:
        visible &= ~(exclude_mask[y1:y2 + 1, x1:x2 + 1] > 0)
    mask_crop = candidate_mask[y1:y2 + 1, x1:x2 + 1] > 0
    covered = visible & mask_crop
    detail_crop = source_detail[y1:y2 + 1, x1:x2 + 1]
    visible_pixels = int(np.count_nonzero(visible))
    overlap_pixels = int(np.count_nonzero(covered))
    minimum_overlap = max(
        int(BODY_BOX_MIN_OVERLAP_PIXELS),
        int(math.ceil(visible_pixels * BODY_BOX_MIN_OVERLAP_FRACTION)),
    )
    box_detail_energy = float(np.sum(detail_crop[visible]))
    covered_detail_energy = float(np.sum(detail_crop[covered]))
    if box_detail_energy > 1e-6:
        detail_coverage = float(np.clip(covered_detail_energy / box_detail_energy, 0.0, 1.0))
    else:
        # There is no contrast energy to lose, so do not invent a detail failure.
        detail_coverage = 1.0

    high_contrast = (detail_crop >= OUTLINE_LEAK_DETAIL_THRESHOLD) & visible
    high_count = int(np.count_nonzero(high_contrast))
    covered_high = int(np.count_nonzero(high_contrast & covered))
    high_coverage = (float(covered_high / high_count) if high_count else float("nan"))

    enough_absolute_overlap = overlap_pixels >= minimum_overlap
    if high_count >= BODY_BOX_MIN_HIGH_CONTRAST_PIXELS:
        # Both ratios must pass: good average energy coverage must not hide a
        # largely omitted high-contrast outline, and vice versa.
        meaningful = (
            enough_absolute_overlap
            and detail_coverage >= BODY_BOX_MIN_DETAIL_ENERGY_COVERAGE
            and high_coverage >= BODY_BOX_MIN_HIGH_CONTRAST_COVERAGE
        )
        combined = 0.65 * detail_coverage + 0.35 * high_coverage
    else:
        meaningful = enough_absolute_overlap and detail_coverage >= BODY_BOX_MIN_DETAIL_ENERGY_COVERAGE
        combined = detail_coverage

    return {
        "raw_overlap_nonzero": overlap_pixels > 0,
        "overlap_pixels": overlap_pixels,
        "visible_box_pixels": visible_pixels,
        "minimum_required_overlap_pixels": minimum_overlap,
        "box_overlap_fraction": float(overlap_pixels / max(visible_pixels, 1)),
        "detail_energy_coverage_ratio": detail_coverage,
        "high_contrast_coverage_ratio": high_coverage,
        "high_contrast_pixels": high_count,
        "covered_high_contrast_pixels": covered_high,
        "combined_detail_coverage_score": float(combined),
        "meaningfully_covered": bool(meaningful),
    }


def _outline_box(draw: ImageDraw.ImageDraw, b: dict[str, Any], w: int, h: int, color: tuple[int, int, int]) -> None:
    poly = b.get("poly")
    if poly is not None:
        pts = [(float(x), float(y)) for x, y in poly]
        draw.line(pts + [pts[0]], fill=color, width=2)
        return
    bounds = rect_bounds(b, w, h)
    if bounds:
        draw.rectangle(bounds, outline=color, width=2)


def build_overlay(rgb: np.ndarray, candidate: np.ndarray, boxes: list[dict[str, Any]],
                  zones: list[dict[str, Any]] | None = None) -> Image.Image:
    base = rgb.astype(np.float32).copy()
    selected = candidate > 0
    tint = np.array([255.0, 35.0, 185.0], dtype=np.float32)
    base[selected] = base[selected] * 0.48 + tint * 0.52
    im = Image.fromarray(np.clip(base, 0, 255).astype(np.uint8), "RGB")
    draw = ImageDraw.Draw(im)
    w, h = im.size
    for b in boxes:
        color = (225, 45, 45) if b["type"] == "body" else ((170, 90, 215) if b["type"] == "header" else (255, 170, 0))
        _outline_box(draw, b, w, h, color)
    for z in zones or []:
        _outline_box(draw, z, w, h, (30, 90, 255))
    return im


def choose_output_dir(path: Path) -> Path:
    path = path.expanduser().resolve()
    stamp = time.strftime("run_%Y%m%d_%H%M%S")
    if path.exists() and any(path.iterdir()):
        candidate = path / stamp
        suffix = 1
        while candidate.exists():
            candidate = path / f"{stamp}_{suffix}"
            suffix += 1
        return candidate
    return path


def save_contact_sheets(images: list[tuple[str, Path]], output: Path, label: str, per_sheet: int = 16) -> None:
    if not images:
        return
    output.mkdir(parents=True, exist_ok=True)
    try:
        font = ImageFont.truetype("DejaVuSans.ttf", 13)
    except OSError:
        font = ImageFont.load_default()
    for start in range(0, len(images), per_sheet):
        chunk = images[start:start + per_sheet]
        cards: list[Image.Image] = []
        for name, path in chunk:
            with Image.open(path) as source:
                im = source.convert("RGB")
            scale = min(1.0, 320 / max(im.size))
            if scale < 1:
                im = im.resize((max(1, round(im.width * scale)), max(1, round(im.height * scale))), Image.Resampling.LANCZOS)
            card = Image.new("RGB", (im.width, im.height + 25), "white")
            card.paste(im, (0, 25))
            ImageDraw.Draw(card).text((5, 5), name[:42], font=font, fill=(10, 10, 10))
            cards.append(card)
        cw = max(c.width for c in cards)
        ch = max(c.height for c in cards)
        cols = 4
        rows = (len(cards) + cols - 1) // cols
        gap = margin = 8
        sheet = Image.new("RGB", (margin * 2 + cols * cw + (cols - 1) * gap,
                                   margin * 2 + 18 + rows * ch + (rows - 1) * gap), (225, 225, 225))
        d = ImageDraw.Draw(sheet)
        d.text((margin, 2), label, fill=(0, 0, 0), font=font)
        for i, card in enumerate(cards):
            x = margin + (i % cols) * (cw + gap)
            y = margin + 18 + (i // cols) * (ch + gap)
            sheet.paste(card, (x, y))
        sheet.save(output / f"sheet_{start // per_sheet + 1:03d}.jpg", quality=88)


def main() -> int:
    args = parse_args()
    anchors_path = args.anchors.expanduser().resolve()
    images_dir = args.images_dir.expanduser().resolve()
    weights_path = args.weights.expanduser().resolve()
    if args.imgsz < 320 or args.min_conf < 0 or args.min_conf > 0.05:
        print("ERROR: --imgsz must be >=320 and --min-conf must be in [0, 0.05]", file=sys.stderr)
        return 2
    if args.dilation < 0 or args.limit < 0:
        print("ERROR: --dilation and --limit must be >=0", file=sys.stderr)
        return 2
    try:
        distances = sorted({int(x.strip()) for x in args.distances.split(",") if x.strip() != ""})
        if not distances or distances[0] < 0:
            raise ValueError
    except ValueError:
        print("ERROR: --distances must be comma-separated non-negative integers, e.g. 0,4,8,12,16", file=sys.stderr)
        return 2

    try:
        anchors_by_image, known_names = read_anchors(anchors_path)
        zones_path = resolve_protected_zones_csv(anchors_path, args.protected)
        zones_by_image = read_protected_zones(zones_path) if zones_path is not None else {}
        images = discover_images(images_dir, known_names)
        if args.limit:
            images = images[:args.limit]
    except Exception as exc:
        print(f"ERROR: {type(exc).__name__}: {exc}", file=sys.stderr)
        return 2
    if not images:
        print("ERROR: no source images matched filenames in anchors.csv", file=sys.stderr)
        return 2

    print(f"Anchors CSV: {anchors_path}")
    print(f"Protected zones CSV: {zones_path if zones_path is not None else 'none'}")
    print(f"Source images: {images_dir}")
    print(f"Matched images: {len(images)} / {len(known_names)} anchor image names")
    print(f"Checkpoint: {weights_path}")
    print(f"Confidence tests: {CONFIDENCE_THRESHOLDS}; mask proximity thresholds: {distances}px; dilation: {args.dilation}px")
    print("This is inference-only; no training and no LaMa run.")
    if args.dry_run:
        if weights_path.is_file():
            print(f"Checkpoint exists ({weights_path.stat().st_size / 1024 / 1024:.1f} MiB).")
        else:
            print("WARNING: checkpoint not found.")
        print("DRY RUN: no inference or output files created.")
        return 0
    if not weights_path.is_file():
        print("ERROR: YOLO checkpoint not found. Pass --weights explicitly.", file=sys.stderr)
        return 3

    try:
        from ultralytics import YOLO
        import torch
        device = "cuda:0" if args.device == "cuda" else ("cpu" if args.device == "cpu" else ("cuda:0" if torch.cuda.is_available() else "cpu"))
        model = YOLO(str(weights_path))
        names_raw = getattr(model, "names", {})
        if isinstance(names_raw, dict):
            class_names = {int(k): str(v) for k, v in names_raw.items()}
        else:
            class_names = {i: str(v) for i, v in enumerate(names_raw)}
        print(f"Loaded model; classes: {class_names}; device: {device}")
    except Exception as exc:
        print(f"ERROR loading YOLO: {type(exc).__name__}: {exc}", file=sys.stderr)
        return 4

    output = choose_output_dir(args.output)
    output.mkdir(parents=True, exist_ok=True)
    report_rows: list[dict[str, Any]] = []
    box_rows: list[dict[str, Any]] = []
    instance_rows: list[dict[str, Any]] = []
    overlays_by_distance: dict[int, list[tuple[str, Path]]] = {d: [] for d in distances}
    box_only_overlays: list[tuple[str, Path]] = []
    error_count = 0

    for image_idx, image_path in enumerate(images, start=1):
        name = image_path.name
        print(f"[{image_idx}/{len(images)}] {name}", flush=True)
        try:
            with Image.open(image_path) as source:
                rgba = source.convert("RGBA")
                rgb = np.asarray(rgba.convert("RGB"), dtype=np.uint8)
                source_alpha = np.asarray(rgba.getchannel("A"), dtype=np.uint8)
            h, w = rgb.shape[:2]
            # A hue-independent detail map lets routing check whether YOLO
            # covers substantial text-like contrast inside each Body OCR box.
            source_detail = ink_strength_map(rgb)
            boxes = anchors_by_image.get(name, [])
            body_boxes = [b for b in boxes if b["type"] == "body"]
            header_boxes = [b for b in boxes if b["type"] == "header"]
            all_box_mask = draw_box_mask((w, h), boxes)
            header_mask = draw_box_mask((w, h), header_boxes)
            image_zones = zones_by_image.get(name, [])
            protected = protected_mask(image_zones, w, h, max(0, args.protected_margin))
            # Box-only baseline: anchors minus protected zones. Distances below are still
            # measured from the unmodified anchors (protection only removes pixels).
            box_only_mask_out = all_box_mask.copy()
            box_only_mask_out[protected] = 0
            box_mask_dir = output / "box_only" / "masks"
            box_overlay_dir = output / "box_only" / "overlays"
            box_mask_dir.mkdir(parents=True, exist_ok=True)
            box_overlay_dir.mkdir(parents=True, exist_ok=True)
            box_mask_path = box_mask_dir / f"{Path(name).stem}.png"
            box_overlay_path = box_overlay_dir / f"{Path(name).stem}.jpg"
            Image.fromarray(box_only_mask_out, mode="L").save(box_mask_path)
            build_overlay(rgb, box_only_mask_out, boxes, image_zones).save(box_overlay_path, quality=90)
            box_only_overlays.append((name, box_overlay_path))
            # Exact Euclidean distance (in pixels) to the nearest anchor-box pixel.
            # Pixels inside any OCR box have distance 0.
            distance_to_anchor = cv2.distanceTransform(
                (all_box_mask == 0).astype(np.uint8), cv2.DIST_L2, cv2.DIST_MASK_PRECISE
            )

            prediction = model.predict(
                source=cv2.cvtColor(rgb, cv2.COLOR_RGB2BGR), imgsz=args.imgsz,
                conf=args.min_conf, iou=0.70, device=device, retina_masks=True, verbose=False,
            )
            if not prediction:
                raise RuntimeError("model returned no prediction result")
            result = prediction[0]
            result_boxes = getattr(result, "boxes", None)
            result_masks = getattr(result, "masks", None)
            confs = result_boxes.conf.detach().cpu().tolist() if result_boxes is not None and len(result_boxes) else []
            cls_ids = result_boxes.cls.detach().cpu().tolist() if result_boxes is not None and len(result_boxes) else []
            polygons = list(result_masks.xy) if result_masks is not None else []
            if len(polygons) != len(confs):
                if len(confs) or len(polygons):
                    raise RuntimeError(f"detection/mask count mismatch: {len(confs)} detections, {len(polygons)} masks")
            instances: list[dict[str, Any]] = []
            for ix, (conf, cls_id, poly) in enumerate(zip(confs, cls_ids, polygons)):
                class_name = class_names.get(int(cls_id), f"class_{int(cls_id)}")
                if not requested_class(class_name):
                    continue
                imask = polygon_mask(poly, w, h, args.dilation)
                pixels = int(np.count_nonzero(imask))
                if pixels == 0:
                    continue
                dist = min_distance_to_boxes(imask, distance_to_anchor)
                hits = []
                for bidx, box in enumerate(body_boxes):
                    overlap_px = overlap_with_box(imask, box)
                    if overlap_px > 0:
                        hits.append((bidx, overlap_px))
                instances.append({
                    "index": ix, "class_name": class_name, "confidence": float(conf),
                    "mask": imask, "pixels": pixels, "distance": dist, "body_hits": hits,
                    "poly": poly,
                })

            # Evaluate both confidence choices against the same inference.
            # Distance filtering is PIXEL-WISE: within each instance, retain only
            # pixels whose distance to the nearest OCR box is <= d. This trims
            # distant parts of a mask rather than accepting/rejecting the whole instance.
            distance_allowed = {d: (distance_to_anchor <= (d + 1e-6)) for d in distances}
            for threshold in CONFIDENCE_THRESHOLDS:
                eligible = [inst for inst in instances if inst["confidence"] + 1e-9 >= threshold]
                # Build the eligible union once. A single pixel overlap no longer
                # counts as a successful body-box detection: assess original detail
                # coverage and high-contrast stroke coverage within each box.
                untrimmed_union = np.zeros((h, w), dtype=np.uint8)
                for inst in eligible:
                    untrimmed_union = cv2.bitwise_or(untrimmed_union, inst["mask"])
                pixels_before_clip = int(np.count_nonzero(untrimmed_union))
                body_coverage = [
                    body_box_coverage_metrics(untrimmed_union, source_detail, source_alpha, body,
                                              exclude_mask=protected if protected.any() else None)
                    for body in body_boxes
                ]
                missing = [i for i, coverage in enumerate(body_coverage)
                           if not coverage["meaningfully_covered"]]
                raw_hit_count = sum(int(coverage["raw_overlap_nonzero"]) for coverage in body_coverage)
                if not body_boxes:
                    route = "MANUAL_REVIEW_NO_BODY_BOXES"
                elif missing:
                    route = "BOX_MASK_FALLBACK_WEAK_COVERAGE"
                else:
                    route = "YOLO_CANDIDATE"

                for d in distances:
                    allowed_pixels = distance_allowed[d]
                    yolo_union = np.zeros((h, w), dtype=np.uint8)
                    partially_clipped_instances = 0
                    clipped_away_instances = 0
                    for inst in eligible:
                        original_mask = inst["mask"]
                        clipped_mask = cv2.bitwise_and(original_mask, allowed_pixels.astype(np.uint8) * 255)
                        original_pixels = int(np.count_nonzero(original_mask))
                        clipped_pixels = int(np.count_nonzero(clipped_mask))
                        if clipped_pixels == 0:
                            clipped_away_instances += 1
                        elif clipped_pixels < original_pixels:
                            partially_clipped_instances += 1
                        yolo_union = cv2.bitwise_or(yolo_union, clipped_mask)
                    candidate = cv2.bitwise_or(yolo_union, header_mask)
                    candidate_before_protection = int(np.count_nonzero(candidate))
                    candidate[protected] = 0
                    total_yolo_pixels = int(np.count_nonzero(yolo_union))
                    pixels_removed_by_clip = max(0, pixels_before_clip - total_yolo_pixels)
                    yolo_inside_boxes = int(np.count_nonzero((yolo_union > 0) & (all_box_mask > 0)))
                    yolo_outside_boxes = total_yolo_pixels - yolo_inside_boxes
                    mask_path = ""
                    overlay_path = ""
                    # Only persist the main 0.05 candidates; 0.10 is a metrics-only control.
                    if threshold == 0.05:
                        output_mask_dir = output / "conf_005" / f"distance_{d:02d}" / "masks"
                        output_overlay_dir = output / "conf_005" / f"distance_{d:02d}" / "overlays"
                        output_mask_dir.mkdir(parents=True, exist_ok=True)
                        output_overlay_dir.mkdir(parents=True, exist_ok=True)
                        mask_file = output_mask_dir / f"{Path(name).stem}.png"
                        overlay_file = output_overlay_dir / f"{Path(name).stem}.jpg"
                        Image.fromarray(candidate, mode="L").save(mask_file)
                        build_overlay(rgb, candidate, boxes, image_zones).save(overlay_file, quality=90)
                        mask_path = str(mask_file)
                        overlay_path = str(overlay_file)
                        overlays_by_distance[d].append((name, overlay_file))

                    report_rows.append({
                        "image": name, "confidence_threshold": f"{threshold:.2f}", "max_distance_px": d,
                        "route_suggestion": route,
                        "body_boxes": len(body_boxes),
                        "body_boxes_hit_by_any_eligible_yolo_mask": raw_hit_count,
                        "body_boxes_meaningfully_covered_by_yolo_mask": len(body_boxes) - len(missing),
                        "body_boxes_missing_or_weakly_covered": len(missing),
                        "body_boxes_missing_yolo_mask": len(missing),
                        "missing_body_box_indices_1based": ";".join(str(i + 1) for i in missing),
                        "weak_coverage_body_box_indices_1based": ";".join(str(i + 1) for i in missing),
                        "minimum_required_body_box_detail_coverage": BODY_BOX_MIN_DETAIL_ENERGY_COVERAGE,
                        "minimum_required_body_box_high_contrast_coverage": BODY_BOX_MIN_HIGH_CONTRAST_COVERAGE,
                        "eligible_instances_before_clip": len(eligible),
                        "instances_with_pixels_after_clip": len(eligible) - clipped_away_instances,
                        "instances_partially_clipped": partially_clipped_instances,
                        "instances_clipped_away_completely": clipped_away_instances,
                        "yolo_mask_pixels_before_distance_clip_union": pixels_before_clip,
                        "yolo_pixels_removed_by_distance_clip_union": pixels_removed_by_clip,
                        "yolo_mask_pixels_after_distance_clip_union": total_yolo_pixels,
                        "yolo_pixels_inside_any_anchor_box": yolo_inside_boxes,
                        "yolo_pixels_outside_anchor_boxes": yolo_outside_boxes,
                        "yolo_pixels_outside_box_fraction": f"{yolo_outside_boxes / max(1, total_yolo_pixels):.6f}",
                        "candidate_mask_pixels_including_header_boxes": int(np.count_nonzero(candidate)),
                        "protected_zone_count": len(image_zones),
                        "protected_pixels": int(np.count_nonzero(protected)),
                        "protected_pixels_removed_from_candidate": candidate_before_protection - int(np.count_nonzero(candidate)),
                        "candidate_mask_path": str(mask_path), "overlay_path": str(overlay_path),
                    })

                # Per-box detail at each confidence threshold. `covered_by_yolo`
                # now means meaningful coverage, while raw overlap is preserved
                # separately to expose the former one-pixel false positive.
                for bidx, body in enumerate(body_boxes):
                    coverage = body_coverage[bidx]
                    total_overlap = sum(overlap_with_box(inst["mask"], body) for inst in eligible)
                    matching_confidences = [inst["confidence"] for inst in eligible if overlap_with_box(inst["mask"], body) > 0]
                    box_rows.append({
                        "image": name, "confidence_threshold": f"{threshold:.2f}",
                        "body_box_index_1based": bidx + 1,
                        "anchor_id": body["anchor_id"], "row": body["row"], "col": body["col"],
                        "box_x1": body["x1"], "box_y1": body["y1"], "box_x2": body["x2"], "box_y2": body["y2"],
                        "covered_by_yolo": int(coverage["meaningfully_covered"]),
                        "raw_overlap_nonzero": int(coverage["raw_overlap_nonzero"]),
                        "overlap_pixel_count_union": coverage["overlap_pixels"],
                        "overlap_pixel_count_sum": total_overlap,
                        "visible_box_pixels": coverage["visible_box_pixels"],
                        "minimum_required_overlap_pixels": coverage["minimum_required_overlap_pixels"],
                        "box_overlap_fraction": f"{coverage['box_overlap_fraction']:.6f}",
                        "detail_energy_coverage_ratio": f"{coverage['detail_energy_coverage_ratio']:.6f}",
                        "high_contrast_coverage_ratio": (f"{coverage['high_contrast_coverage_ratio']:.6f}" if math.isfinite(coverage["high_contrast_coverage_ratio"]) else ""),
                        "high_contrast_pixels": coverage["high_contrast_pixels"],
                        "covered_high_contrast_pixels": coverage["covered_high_contrast_pixels"],
                        "combined_detail_coverage_score": f"{coverage['combined_detail_coverage_score']:.6f}",
                        "coverage_status": "meaningful" if coverage["meaningfully_covered"] else "weak_or_missing",
                        "matching_instance_confidences": ";".join(f"{v:.4f}" for v in matching_confidences),
                    })

            for inst in instances:
                for threshold in CONFIDENCE_THRESHOLDS:
                    if inst["confidence"] + 1e-9 < threshold:
                        continue
                    instance_rows.append({
                        "image": name, "confidence_threshold": f"{threshold:.2f}", "instance_index": inst["index"],
                        "class_name": inst["class_name"], "confidence": f"{inst['confidence']:.6f}",
                        "mask_pixels_after_dilation": inst["pixels"],
                        "minimum_distance_to_any_anchor_px": f"{inst['distance']:.3f}",
                        "intersected_body_box_indices_1based": ";".join(str(i + 1) for i, _ in inst["body_hits"]),
                        "intersected_body_box_count": len(inst["body_hits"]),
                    })
        except Exception as exc:
            error_count += 1
            print(f"  ERROR: {type(exc).__name__}: {exc}", file=sys.stderr)
            report_rows.append({"image": name, "status": f"error: {type(exc).__name__}: {exc}"})

    def write_csv(path: Path, rows: list[dict[str, Any]]) -> None:
        if not rows:
            return
        keys = list(dict.fromkeys(key for row in rows for key in row.keys()))
        with path.open("w", encoding="utf-8-sig", newline="") as f:
            writer = csv.DictWriter(f, fieldnames=keys)
            writer.writeheader()
            writer.writerows(rows)

    write_csv(output / "routing_report.csv", report_rows)
    write_csv(output / "body_box_coverage.csv", box_rows)
    write_csv(output / "instances.csv", instance_rows)
    save_contact_sheets(box_only_overlays, output / "box_only" / "contact_sheets", "Box-only masks (all body + header rectangles)")
    for d, entries in overlays_by_distance.items():
        save_contact_sheets(entries, output / "conf_005" / f"distance_{d:02d}" / "contact_sheets", f"YOLO conf 0.05 pixelwise trim: retain mask pixels <= {d}px from nearest anchor box + headers")

    # Aggregate a quick summary for stdout/README.
    main_rows = [r for r in report_rows if r.get("confidence_threshold") == "0.05"]
    unique_images = len({r["image"] for r in main_rows})
    by_d: list[str] = []
    for d in distances:
        subset = [r for r in main_rows if int(r["max_distance_px"]) == d]
        fallbacks = len({r["image"] for r in subset if r.get("route_suggestion") == "BOX_MASK_FALLBACK"})
        avg_after = float(np.mean([int(r["instances_with_pixels_after_clip"]) for r in subset])) if subset else 0.0
        avg_removed = float(np.mean([int(r["yolo_pixels_removed_by_distance_clip_union"]) for r in subset])) if subset else 0.0
        by_d.append(f"{d}px: box fallback {fallbacks}/{len(subset)}, mean instances with pixels after clip {avg_after:.2f}, mean union pixels clipped {avg_removed:.0f}")

    readme = [
        "YOLO mask routing audit (inference only; no training and no LaMa).",
        f"Images source: {images_dir}", f"Anchors CSV: {anchors_path}", f"Weights: {weights_path}",
        f"Images processed: {unique_images}", f"Distance sweep: {distances}; dilation: {args.dilation}px",
        f"Body-box meaningful coverage thresholds: overlap >= {BODY_BOX_MIN_OVERLAP_PIXELS}px / {BODY_BOX_MIN_OVERLAP_FRACTION:.2%} of visible box; detail energy >= {BODY_BOX_MIN_DETAIL_ENERGY_COVERAGE:.0%}; high-contrast pixels >= {BODY_BOX_MIN_HIGH_CONTRAST_COVERAGE:.0%} when present.",
        "Route rule: every type=body box must have a non-trivial YOLO overlap and sufficient coverage of source local-contrast energy and high-contrast pixels; one-pixel hits do not count. Weak coverage routes to BOX_MASK_FALLBACK.",
        "Proximity rule: pixel-wise trim each eligible YOLO mask. Keep only mask pixels whose distance to the nearest anchor-box pixel is <= the configured limit. Always union header rectangles in full.",
        "This clips distant parts of a mask, even when another part of the same instance is close to a box; instances are not accepted/rejected as indivisible objects.",
        "Use routing_report.csv for per-image summary, body_box_coverage.csv for raw overlap and detail-coverage ratios per body box, instances.csv for per-instance confidence/minimum distance, and contact sheets to visually tune clipping.",
        "This is a heuristic report; the best distance must be chosen from the contact sheets and LaMa results, not inferred from overlap statistics alone.",
        "Never modified source images, anchors.csv, raw/, cleaned/, or existing audit results.",
        "",
        *by_d,
    ]
    (output / "README.txt").write_text("\n".join(readme) + "\n", encoding="utf-8")
    print("\n=== ROUTING AUDIT COMPLETE ===")
    print(f"Processed images with report rows: {unique_images}; errors: {error_count}")
    print(f"Output: {output}")
    print(f"Per-image report: {output / 'routing_report.csv'}")
    print(f"Per-body-box details: {output / 'body_box_coverage.csv'}")
    print(f"Per-instance details: {output / 'instances.csv'}")
    print("Per-pixel distance-clip summary (conf=0.05):")
    for line in by_d:
        print("  " + line)
    return 0 if error_count == 0 else 1


if __name__ == "__main__":
    raise SystemExit(main())
